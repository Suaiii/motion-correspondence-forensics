## 可否证问题与精确条件

假设一个视频仅由同一 patch 特征场的网格循环平移构成，时间分支能否读取
超出静态图的新增信息？本诊断仅检验这个精确特征空间模型，不能假设真实
DINO 特征在图像平移时也精确等变。保留当前温度、扰动和响应定义，不另调参。

令 Z 是一帧归一化 patch 特征，Q_t 为帧 t 的置换矩阵，Z_t=Q_t Z，
P=row_softmax(ZZ^T/tau)。逐行 softmax 与行列置换相容，故

    P_ab = Q_a P Q_b^T
    P_ab P_bc = Q_a P² Q_c^T
    P_ac = Q_a P Q_c^T

直接 JS 因共同目的节点重排不变，其响应图只是基准静态 JS 的 Q_a 重排。
扰动项为

    P_ab Pi P_bc = Q_a P (Q_b^T Pi Q_b) P Q_c^T

在 full-middle-support 模式，若 Q_a、Q_b 与全部 Pi 可交换——网格上循环
平移与当前四方向循环位移满足该条件——上式化为 Q_a P Pi P Q_c^T。
静态 (a,a,a) 的对应项为 Q_a P Pi P Q_a^T。共同列置换不改变逐行 JS，
所以**每个时间三元组 (a,b,c) 的完整响应图恰等于静态 (a,a,a) 的响应图**。
该结论无需 P²=P，不要求时间平移速度恒定；它要求特征内容严格为同一场的置换。

任意置换未必与固定空间 Pi 交换；固定中间支持掩码也未必与 Q_t 交换。
因此该证明不适用于一般运动、遮挡、新物体、特征变化或固定内部区域分支。
平移不变可能是期望性质：本反例限制归因，并不单独否定取证价值。

## 六组读出暴露了另一种权重

当前六组三元组的起点为 [0,1,2,3,0,1]，次数为 [2,2,1,1,0,0]。
令 h_i 为静态 i 响应图经过任意相同空间编码器及空间均值的向量。在上述条件下，

    local_temporal = (2h_0 + 2h_1 + h_2 + h_3)/6

只要语义分支保持相同六帧，使用相同分类头参数也会得到相同 logits。
空间编码器即使有零填充边界，这个按起点匹配的等式仍成立，因为输入图逐组相同。
它不同于 uniform-static 的六帧平均，也不同于上一草案的总角色次数
[2,3,4,4,3,2]/18。总次数加权的提案未声称匹配全部非线性交互；本结果进一步
具体说明它不能匹配哪一种可解析情形。

建议增加 **anchor-matched static 作为机制诊断提案**：按每个时间组的 a 帧
生成 (a,a,a)，保持相同组数及相同语义。这个诊断局部分支没有同等使用全部六帧，
因此不能替代 v1.1 要求的同六帧 uniform-static 强基线。若采用，须在审计前冻结
定义并明确是否另训；不得结果出来后挑最有利的静态版本。对 B、C 也须分别
从自己的时间图推导起点，而不能沿用 A 的权重。
