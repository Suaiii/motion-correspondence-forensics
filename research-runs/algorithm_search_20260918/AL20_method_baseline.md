# AL20：有限交叉增量、紧凑强基线与正则合同

cc-al20-al24-baseline-matching-20260919；AL20；researchagent_next；2026-09-19。
本文件不改变OR1、原h/eta/lambda、匹配描述b或历史结果。
目标是审查同四调用下的最强紧凑对照，不实现新检测器或拟合权重。

## 1. 有限h精确恒等式

令v_j(u)=R_j(u)−u、P_j(u)=u+h v_j(u)，h≠0，所有值在同一坐标/槽位和共同支持上。

    d_a = [v_a(P_b(u))−v_a(u)]/h,
    d_b = [v_b(P_a(u))−v_b(u)]/h.

直接展开端点：

    P_a(P_b(u))−P_b(P_a(u))
      = h[v_b(u)+v_a(P_b(u))−v_a(u)−v_b(P_a(u))]
      = h²(d_a−d_b).

因此**K=d_a−d_b在有限h下精确成立**。不要求h趋0、可微、C²或可逆；
夹断等非线性已包含在R中也不破坏这条有限代数等式，但它不赋予几何或生成来源解释。
若输出尺寸/槽位不同，则减法本身未定义；这里不声称像素物理一一对应。

四调用足够：R_a(u)、R_b(u)、R_a(P_b(u))、R_b(P_a(u))。
P_a/P_b及各v由已有节点直接相减；不需要第5次probe。完整端点依然对所有对照开放。

## 2. 每滤波的完整三元组

对同一个固定**线性**H_l、同边界策略/支持/平均尺度，定义

    A_l=mean||H_l d_a||²,
    B_l=mean||H_l d_b||²,
    C_l=mean< H_l d_a,H_l d_b >,
    D_l=mean||H_l v_a(u)||²+mean||H_l v_b(u)||²+eta.

D_l必须与候选共用，不能给基线改分母、独立归一化或去掉eta。
当D_l>0，令z_l=(A_l/D_l,B_l/D_l,C_l/D_l)，则

    q_l=mean||H_l K||²/D_l=z_l,1+z_l,2−2 z_l,3.                  (1)

这对非线性读出或不同支持/归一化不自动成立。有限精度实现的不同运算次序也未被说成bitwise相同。
须保留所有三项，包括可负的内积C，而非仅两个能量或其平均。
线性代数层面，A=B=1而C=1或−1给完全不同的差分能量；这说明只保留能量可能遗漏对齐关系。
该说明是抽象Gram关系，没有运行新probe或声称某个实际AE必访问这两种配置。

将4组三元组拼成z∈R^12，即紧凑同信息强基线。
**这个z不是AL12/AL24用于匹配的12维b**：b在既有规则下只做匹配，不能因为基线改变而重选配对。
算法比较必须使用同一输入/支持/四调用、同一配对表和同一层权重。

## 3. 固定与学习读出、参数数目

候选s_w=w^Tq、w∈R^4。令T∈R^(12×4)每个block为(1,1,−2)^T，则

    q=T^T z,   s_w=(Tw)^T z.

- **固定重构对照**：按(1)从三元组复算q，无学习参数；必须在数值政策相同的条件下重建候选读出。
- **约束学习对照**：beta=Tw，仅4个自由权重；与候选同输入、同配对、同损失/正则时是相同函数与目标，不能伪装为不同新信息。
- **自由紧凑对照**：s_beta=beta^T z，12个自由权重；函数类包含候选，但参数更多，不能用零padding说成4参数。
- **完整端点/方向对照**：保留原向量及全部中间/端点的强模型；与紧凑统计一起报告，不只选择较弱单步标量。

只比较8个单步误差会遗漏普通交叉增量和内积；相对该弱压缩的差异不能自动成为独立新信息。
OR1的有限数据归纳约束仍可能有作用，但需要真实、匹配强基线的结果支持，不能由包含关系反推测试优劣。

## 4. 独立核对AL23的正则诱导度量

T的各列支撑不重叠，每列平方和1+1+4=6，所以

    T^T T=6 I_4,    ||Tw||²=6||w||².                              (2)

原候选固定lambda=1/1000。若自由基线用相同字面lambda||beta||²，
在指定嵌入beta=Tw上，它对同分数施加6倍惩罚。这是参数化差异，不是特征作用。
“6倍”针对该标准嵌入，未声称有限训练数据上任何同预测的beta都具有该范数；
若特征表有核空间，可能存在其他同预测参数，需另作可识别性分析。

一个预先声明、含候选同惩罚子空间的自由基线可使用

    L_free(beta)=L_data(beta; fixed z/pairs/weights)+(lambda/6)||beta||²,
    lambda_free=1/6000.

代入beta=Tw得L_free(Tw)=L_candidate(w)，故

    min_beta L_free(beta) <= min_w L_candidate(w).                 (3)

这是同一个固定数据/配对/权重目标的关系。若配对、权重、支持或正则度量不同，该比较不能照搬。
它既不证明普通浮点求解器达到了相应全局最优，也不预言测试AUROC、FPR、域外泛化更优。
相同lambda且未做度量换算时，函数类包含仍成立，但不能直接引用(3)作为匹配训练目标结论。
本包没有改变旧候选lambda或拟合lambda/6模型；1/6000仅是未来基线合同的事前数学定义。

## 6. 科学判断边界

紧凑三元组可以精确包含候选所用读出；候选不比同完整三元组拥有新的观察信息。
它是否以更合适的4权重约束改善有限样本泛化是另一问题，不能仅凭普通函数包含否决或确认整个候选。
未来必须同时保留固定重构、同4自由度约束、自洽正则的自由12维，以及完整端点强对照。
真实创新、数据/资源、来源/祖先/时钟、正式五种子和最终集门槛不变。
