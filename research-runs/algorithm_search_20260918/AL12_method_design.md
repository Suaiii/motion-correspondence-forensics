## 1. 目标、信息与理论边界

生成内容标签Y=1，摄像来源内容Y=0；是否经过VAE另记为处理属性。
严重内容改变或来源不明的重建进入ambiguous，不凭处理名称自动改成生成类。
固定生产解码器D_i及其编码器E_i，R_i=D_i∘E_i（使用确定性posterior mean）。

    C=x_camera,
    C_i^(1)=R_i(C),       G_i^(1)=D_i(z_gen),
    C_i^(2)=R_i(C_i^(1)), G_i^(2)=R_i(G_i^(1)).                       (1)

若D_i推前的两类latent分布相同，则所有只看输出的检测器都不可分；加入确定性探针也不能增加来源信息。
这是必要边界，不说明现实分布已经相同。反过来，仅仅latent分布不同也不够：D_i可以压掉差异。
正文不靠这两个极限作现实判断。

训练时可知道生产D_i、来源/祖先、处理深度k、条件与处理链，用于分层和审核；
这些字段不进入推断头。测试仅得到待测视频u、其可审计时间/空间支持，以及**事先固定的两个公开重建探针**R_a,R_b。
不需要未知生成器身份、其权重、真实latent、训练提示词或同场景真实对应物。
probe bank不得在看留出生成器结果后扩充或选择。严格未见decoder测试要求D_*不属于训练生产decoder或probe bank。

## 2. 一个有依据、但必须被数据检验的机制假设

VAE重建训练把编码后的摄像内容经解码恢复；latent生成模型拟合编码latent分布。
已有生成器结构/损失并不保证有限训练/采样下这两类分布相等，也不保证它们在**其他固定重建器**下的局部响应不同。
不能从“没有显式训练该性质”推出一定存在漏洞。

本设计提出更强、可否证的局部假设H-OR：在相同生产decoder、处理深度、最终编码及相近的一阶重建误差/纹理条件下，
生成latent的有限拟合偏差可能把输出推到重建场交互不同的位置；该交互差异至少有一部分不能由单步误差解释，
并能在完整留出生产decoder后保留。其数学版本如下：

- 在一个内容/支持条件邻域，可将摄像重建输出记作u，生成输出的分布偏移方向记作δ。
- 单步基线b(u)对δ近似不敏感（局部J_b δ≈0），但两个重建场的交互F对δ敏感（J_F δ不为零）。
- F在该邻域的近似、该偏移方向的存在及跨decoder稳定性都是**假设**；不是VAE损失的定理。

这比“两个分布可能不同”多出一个明确预测：**在匹配b以后，顺序交互仍有条件增量**。
若J_F在这些方向同样为零，或剩余增量仅由内容、编码、处理历史、几何变化解释，关闭OR1。
预注册中将保留这样失败的算子与数据情形，不调方向/温度让它必然成立。

## 3. 推断构造：两条相同调用量的软重建路径

两个R_j的所有调用使用相同固定配置、确定性编码、相同声明输出网格/槽位合同。
槽位对齐仅保证张量相减定义在共同坐标上，不证明非线性重建像素与传感器原帧物理一一对应。定义

    v_j(u)=R_j(u)-u,
    P_j^h(u)=u+h v_j(u)=(1-h)u+h R_j(u),   h=1/8,
    u_a=P_a^h(u), u_b=P_b^h(u),
    u_ab=P_a^h(u_b), u_ba=P_b^h(u_a),
    K_ab^h(u)=[u_ab-u_ba]/h².                                     (2)

外层在右到左次序上执行；ab路径先b后a。每条路径各调用a、b一次，混合系数也相同。
实现共享前级u_a/u_b，总计**4次E+D重建调用**，并非一次或两次总调用。
中间结果使用浮点张量，不分别写成有损视频；两端不应用不同编码/裁剪/滤波。
这是主动、已知的顺序干预，不是从原视频猜历史顺序，更不是改变生成来源的因果反事实。

设v_a,v_b在邻域C²，Taylor展开给出

    P_a^h(P_b^h(u)) = u+h(v_a+v_b)+h² J_va v_b+O(h³),
    P_b^h(P_a^h(u)) = u+h(v_a+v_b)+h² J_vb v_a+O(h³),
    K_ab^h(u) = J_va v_b-J_vb v_a+O(h).                            (3)

一阶和消去，留下经典向量场交换交互。推导不要求新的基础统计量，也不证明剩余项与Y相关。
ReLU切换、裁剪、随机采样、缓存错位或离散网格变化可能违反局部平滑假设；不能无条件把真实输出差解释为式(3)。
对固定线性重建器A、B，式(2)严格等于(AB−BA)u，与h无关。
交换probe标签会使K变号；下面读出对这个变号不变。

### 固定轻量读出与可部署输出

四个固定线性滤波H_l：恒等、空间Laplacian/4、标准归一化Sobel-x、Sobel-y；同样作用于所有RGB通道。
不搜索周期、不选择有利patch，不引入H-P0相位轮廓。定义四维特征

    e_jl(u)=mean ||H_l v_j(u)||²,
    q_l(u)=mean ||H_l K_ab^h(u)||² / (e_al+e_bl+η),   η=10^-12,
    s_w(u)=w^T q(u),                                               (4)

mean在同一时空/通道支持上取。主版本仅4个线性权重，无额外MLP/语义融合/SNN。
分数方向由训练确定一次，不能为每个留出decoder翻转。阈值仅在独立摄像来源校准池中锁定；
在校准前输出未校准logit和coverage，不能称概率或真实性证明。
整体probe误差接近数值精度时报告不稳定/无信息；不得以低分自动判真。

```text
input: u, native-time/support record, frozen probe pair a,b, h, fixed filters, w
validate shared input/output grid, deterministic settings, and temporal correspondence
ra = R_a(u); rb = R_b(u)
ua = (1-h)*u + h*ra; ub = (1-h)*u + h*rb
uab = (1-h)*ub + h*R_a(ub)
uba = (1-h)*ua + h*R_b(ua)
K = (uab-uba)/h^2
q = four fixed filtered energy ratios
return dot(w,q), coverage, numerical/path audit fields
```

中间张量、两端点与所有单步误差对强基线同样开放。K是这些数据的确定函数，不能声称新增可观察信息；
所尝试的价值是一阶抵消的归纳约束及来源标签下的匹配训练。完整端点对模型理论上可自行计算K，必须实际比较。

## 4. 处理链和标签：能排除什么、不能排除什么

| 输入 | 来源标签 | probe之前的E_i / D_i调用数 | 任一probe路径额外调用 |
|---|---:|---:|---|
| C | 0 | 0 / 0 | E_a,D_a及E_b,D_b各一次 |
| C_i^(1) | 0 | 1 / 1 | 同上 |
| G_i^(1) | 1 | 0 / 1 | 同上 |
| C_i^(2) | 0 | 2 / 2 | 同上 |
| G_i^(2) | 1 | 1 / 2 | 同上 |

主要机制比较为C_i^(k)对G_i^(k)，k=1、2分别分层，D_i次数相同。
初始latent来源的编码过程本来不同，表中不隐藏这一个E_i差异，也不把“同D次数”说成两条生成流程完全相同。
遵守AL13：先构造原始浮点C/R/R2/G/G2臂，再施加同一最终传播A_κ，probe的实际输入为
u=A_κ(C_i^(k))或A_κ(G_i^(k))。不在两次生产重建之间为某类单独插入编码，也不在两个soft probe中间有损写盘。
未知历史处理保持unknown；新VAE导出时钟单独记录，不能直接冒充传感器原始PTS。
软probe含原输入的混合旁路，因此记录完整调用DAG与系数，不把混合结果谎称纯串行两次重建。
最终编码、缓存清理、首帧/上下文、条件输入、采样和支持规则在两个Y类及两条probe路径上保持一致。

C与其重建是同祖先处理对；G与其再重建也是同祖先处理对。
同decoder的摄像内容与生成内容通常不是同一物理场景，不能把跨类匹配当成完整因果配对。
拍摄设备、内容、训练素材和未知历史仍需独立控制；OR1不替代AL13合同，本文件不编写或覆盖AL13。

## 5. 训练：匹配条件下的来源排序，不改摄像重建标签

训练样本先按g=(生产decoder i，处理深度k，最终编码/采样合同)分层。
在每层内，用固定基线描述b做跨类匹配；b包括8个单步e_jl及4个原输入H_l能量，共12维。
尺度仅从各层训练摄像重建样本确定：使用该层均值和max(标准差,10^-6)；费用为标准化后的均方距离，RMS caliper固定0.5。
在caliper允许的二分图中先最大基数、再最小总费用进行一对一匹配，不放回；平局按冻结ID字典序。
匹配前在每个g内按root_origin_id各保留一个预定派生代表（按冻结ID选择），避免该层内派生臂数量增加权重。
层间宏平均可能使出现在更多层的祖先具有更大累计训练权重，须显式报告，不宣称全局祖先权重已经完全相等。
所有划分/统计区间仍以完整祖先连通组为单位，不能把多层或传播派生臂当作独立科学样本。
不看q、模型分数或留出标签选择配对。没有共同支持的层不扩大caliper挽救，报告样本数与排除率。

对匹配集M_g={(u^+,u^-)}，其中Y^+=1、Y^-=0，拟合

    L(w) = mean_g mean_(u+,u- in M_g)
             log(1+exp(-(s_w(u+)-s_w(u-)))) + 10^-3 ||w||².        (5)

这是普通配对logistic排序，不将损失本身声称原创。生产i、k、b只用于训练分层/匹配，不进入s_w。
排序无法确定截距，故主版本不拟合截距；之后的真实校准池确定统一阈值。
若匹配后q与来源没有关系，正则解应趋向无效读出；不通过增加head容量或改匹配条件修饰失败。
匹配不等同条件独立证明，caliper会改变训练分布，必须报告与完整未匹配测试的差距。

原始C不用于与一次D的G构造主要“同剂量”排序；它必须进入独立校准和原始来源测试。
在C_i^(k)上训练能否覆盖原始C仍是待检验的域外问题，不能因控制组表现好就宣称可部署检测完成。

## 6. 最小解析例与失败例（均未运行）

### 一个确实不同于两个单步标量误差的例子

设二维以外的三维重建矩阵

    A=diag(1/2,1,1),
    B=(1/2) * [[0,1,0],[0,0,1],[0,0,0]].                           (6)

二者算子范数不超过1，AB−BA=−(1/4)e_1 e_2^T。
对u=e_2与u'=e_3，输入范数均1，A单步平方误差均0，B单步平方误差均5/4；
但||K(u)||²=1/16，||K(u')||²=0，恒等滤波下η→0的q分别为1/20与0。
这只证明所构造响应不是两个标量重建误差的同义改写。
完整原输入、误差方向/所有端点仍能区分这两个向量；它们不是实际生成/摄像样本，不证明真实性或超越完整强基线。

### 必须保留的失败

- 若A与B对角或更一般地可交换，则K=0，即使两类输入本来不同，也可能完全无检测能力。
- 若probe只是常量加法，两个顺序相同；大单步误差仍不会产生K。
- 某些非交换矩阵使||K(u)||仅取决于已有单步误差/输入范数；非交换性本身不保证额外判断。
- 即使K非零，若同一D下两来源的K分布一致，任何OR1读出都无增量。
- 只要共同后处理改变了响应且与来源关联，K仍可能成为处理指纹；等调用次数并不消除所有历史混杂。

真实方向不在纸面规定为“生成更大”或“生成更小”，更不能把式(6)人工正例作为AUROC证据。

## 7. 可否证预测与强基线

核心预测是**同D同k、匹配一阶误差后仍有源内容增量，且不依赖生产D在probe bank中**。
以下任一结果都会否决OR1当前机制或其泛化主张：

1. 相同VAE摄像重建C_i^(k)被系统性判为生成，仅处理深度就解释分数；或者C原始摄像FPR失控。
2. 同输入静态纹理、时间频谱、单步误差/误差方向、重复重建或完整两端点对的匹配头达到同样效果。
3. 关闭训练匹配、改用普通重建增强/一致性/域对抗后没有差别：不能把共同数据清洗收益计给新构造。
4. 在完整留出的生产decoder/生成器/真实来源、未见codec或插帧路径下，条件增量消失。
5. 仅有ε很大、clip饱和、首帧错位、时间长度不同或随机重建噪声时出现分离，局部响应解释失效。
6. 相同输入两次确定性计算的数值差与K同量级，或探针顺序交换后能量/分数不保持，应先判实现/数值失败。

必备比较分层：

- 同4维/4权重：普通单步误差的固定聚合、固定自重复重建特征、静态/频谱描述各给完整规则。
- 更强完整特征：全部8个单步误差、方向与端点；允许更多参数并如实报告，不为表面参数匹配砍掉基线信息。
- 同计算预算：4次AE调用的自重复重建对照，与OR1相同probe bank；另有直接使用OR1全部中间/端点数据的学习对照。
- 同输入/同容量头：在统一冻结特征维度与网络预算下比较；输入维度/有效参数差单列，不借零padding虚称容量完全相同。
- 原生RIFT/WaveRep/G2VD等与适配来源标签/帧数的版本分表，不将改标签后的模型当作者原方法。

正则系数、ε与匹配规则不能在留出生成器标签上重选。CPU检查成功不覆盖这些数据条件。
