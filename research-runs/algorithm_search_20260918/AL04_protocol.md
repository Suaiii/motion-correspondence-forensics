## 3. 信息权限与公平比较

H-J全部比较臂获得相同三对**联合**Q与声明质量；P=mQ仅是均匀质量下的条件转移。
不将row-softmax改成双随机的归一化变化算作DJ收益。保存原始Q、DJ拟合Gamma、同Q乘法JS、
三个方向条件转移乘法L1残差、三对熵及质量误差。JS以自然对数、均匀anchor平均计算。
这些是C公式的乘法原语比较，未运行完整16×16 C检测器或头，不能报告C检测性能。

HT所有可部署臂获得完全相同keys、payload、温度和支持元数据；不得传标签、真实路径、生成分布或oracle W。
基线W=P_ab(i,j)P_bc(j,k)/m由可见keys推导，mu按W的实际单点边际计算；普通三阶为同W中心化三重外积的Frobenius范数。
未对齐臂固定i=j=k，仍可访问全部相同输入；它仅仅用于解释对齐变化，不作为唯一强基线。
静态对照保存完整(key,payload)的二阶矩阵，不能仅以payload均值相同声称静态不可分。
另存全索引余弦row-softmax Q元组和逐坐标时间中心三阶。计算复杂度不同须报告；本包不拟合分类头或声称容量匹配。

生成见证Gamma及信息论p_eta仅提供给审计者，绝不进入候选推理。
聚合pair表的整个元组相等确实意味着仅输入该元组的确定函数无法区分；
同一条样本的((X,Y),(Y,Z),(X,Z))却保留共享样本身份，能够恢复(X,Y,Z)。
脚本保存其8个完整观测原子并比较联合概率，不能用几个摘要或分别边际替代完整观测元组验证。
全索引Q的相同仅限明确的Q接口；原始特征不同仍可让更强模型区分。

HT公共payload符号翻转保持完整余弦Q，但有符号三阶翻转、范数不变。完整静态(key,payload)二阶还可能变化。
因此“Q相同、某坐标分量不同”不能证明有稳定新增机制。payload子空间旋转不证明任意key/payload混合旋转不变。
幅度.75/1.25固定检验普通三阶的立方缩放；逆序与错误keys只记录结果，不预设普遍时间排列不变量或低熵必然正确。

## 4. 否证表与失败分类

| 主张 | 必须阻止放行的观察 | 解释与下一步 |
|---|---|---|
| DJ能区分歧义与不相容 | 已有合法Gamma的输入却DJ显著正；或违背事件下界 | 先查数值与定义；成立即推翻本实现/主张，不调温度消去 |
| 有限正核静态为零 | 完整质量、tau>0、指定构造中DJ>1e-8 | 解析/数值反例；外推条件另列 |
| DJ包含Q以外信息 | 相同Q被当作新信息来源 | 信息主张错误；函数非线性不是新观测 |
| HT条件化带来独立增量 | 同W普通三阶与候选张量/读出等价 | 拒绝该版本的新目标贡献，不代表所有HT路线失败 |
| 全索引参照产生新残差 | W本来就是声明pair约束的最大熵Markov连接 | 参照退化；应保留零残差，不改标签 |
| 仅有高阶能区分 | 完整静态二阶或全索引Q已经不同 | 低阶压缩/信息权限解释，需更强匹配基线 |
| 稳定坐标无关机制 | 公共符号/旋转只改变signed分数而不改变不变读出 | 坐标依赖，不能挑符号方向报告收益 |
| 对齐是目标创新 | 只超过未对齐，却不超过同W普通三阶 | 仅支持对齐有效；要让所有强臂使用同样对齐 |
| 遮挡鲁棒 | 非均匀或缺支持被拒绝 | coverage_only；拒绝数量不能作鲁棒性成绩 |
| 新候选已测试 | 无已绑定实现、异常或输出缺失 | pending/implementation_failure，无候选分数 |

分类：`restricted_structural_check`、`coverage_only_not_robustness`、`information_contract_example`、
`baseline_arithmetic_only`、数值/接口failure与candidate pending分开。仅在声明域内的有效反例可否证对应主张。

不兼容证书：A={a=b}, B={b=c}, C={a!=c}，任意联合有Pr(A)+Pr(B)+Pr(C)<=2。
若输入三对Q的对应和为2+v，任意拟合三对边际总L1至少2v，因为总质量均为1，单事件概率差不超过L1/2。
故DJ>=2v/3。这个证书与参考LP实现独立，不另写AL01求解器。LP自身还核对Gamma非负、单点质量、重算目标。

质量准入1e-10比原参考1e-8严格，作为AL04适用域声明；不修原参考，不将5e-9容差区间误差当科学信号。
LP零与不变量阈值1e-8、重算目标1e-7、普通数组关系1e-10。阈值固定，不据结果改变。
已知 `symmetric_kernel_coupling` 未验证有限正温度：原文件只读，AL04入口固定并验证tau=.1；
负温度不属于正核命题的反例。本包记录已知缺陷，不再重跑AL03负温度实验，不声称缺陷已修复。
