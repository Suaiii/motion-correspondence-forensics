# AL81 protocol

The package computes only a fixed weighted paired generator-macro AUROC point estimand on six synthetic records. It uses equal generator weight, shared ancestor weights, exact tie value 1/2, and null for missing support. The standard-library Fraction reference is separate from the rank implementation. Seeds are labels for repeated deterministic checks and do not count as scientific training seeds. No confidence intervals, bootstrap, data, model, media, server or GPU execution is authorized.
