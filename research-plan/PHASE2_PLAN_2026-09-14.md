# 第二阶段：从内部融合增益走向跨来源视频取证

状态：规划已冻结首版，启动审计已执行。当前任务 DAG 仍是 `task-hermes/project.json`。本文件替代旧路线作为第二阶段入口，历史实验、预算上限和原始证据继续保留。

## 1. 这阶段要回答什么

**一个视频对“正确运动对应”和“受控错误对应”的响应差异，是否比绝对残差强度更容易跨来源迁移？**

0.05 是 5 个 AUROC 百分点，并非准确率增加 5%。内部增益本身值得研究；当前真正的问题是外部增量仅 +0.0034，且区间跨零。仅仅把内部 0.886 推高，不能解决这个问题。

阶段目标：在独立来源的开发验收上，找到超过简单融合及强表征基线的最小方法；只有通过后才扩展训练和最终确认。

## 3. 主路线：视频内部的受控响应

### H1：用相对响应替代绝对强度

对一个视频的同一位置、同一时刻，计算估计正确对应的残差 `e0`，以及四个固定错误对应的残差 `e1...e4`。所有分支保留相同的小数插值权重、一次 remap 和同一支持区域。

候选核心量：

`r = (median(e1...e4) - e0) / (MAD(e1...e4) + tau)`。

- `tau` 仅由训练数据确定；记录零分母、裁剪比例与低纹理失败。
- 先保留局部图和时间序列，再做分位数/小型无序读出；不能仅仅重命名现有四维统计量。
- 四个错误对应采用固定随机种子，在整数位移幅度分箱内置换；原始小数位移保留。
- 比较分母归一化、多对照取中位数和普通差分各自的作用。
- 这只是可能抵消共同幅度变化的启发式；不声称对任意编解码、遮挡或非线性退化严格不变。

新意候选在于：对同一视频建立可匹配的算子参照，测量其响应形状，并证明响应能迁移。运动补偿、残差和归一化本身均不作为新颖性主张。

**否证方式：** 在第二真实来源和未见生成器上，不优于普通差分、fractional 单路及简单拼接，或者优势随插值核/光流算法切换而消失，则拒绝 H1。

### H2：仅在 H1 成立后加入可靠性读出

按前后向对应一致性、局部纹理与位移截断率估计对应可靠性。先固定规则再考虑学习权重。

- 对照均匀读出、同覆盖率随机区域、仅可靠性特征和仅 mask 特征。
- 保留全部视频；困难区域可降低权重，但必须报告有效覆盖率和失败组。
- 若仅高可靠区域有增益，检查它是否仅筛掉难例；不能报告筛选后的高分代替总体性能。
- H1 已通过且 H2 有额外来源外增益，才允许做小型可学习读出。

**否证方式：** 同覆盖率随机区域同样有效、mask-only 足以复制增益，或最差来源恶化，则删除可靠性模块。

### 可选小实验：响应随时间间隔的变化

仅在 H1 通过后，固定两种物理时间间隔，比较响应随间隔变化的斜率。与相同帧数、相同 FLOPs 的单间隔模型比较。若只是多看帧带来的收益，不设独立贡献。

第二阶段最多两次主候选尝试：H1；H1 有效但局部对应不稳时的 H1+H2。时间间隔实验为解释性扩展，不得变成无限结构搜索。

## 4. 不预设来源对抗是答案

旧开发集的来源与真假完全关联。直接消除 source identity 可能同时抹去标签信号。

- 先建立至少两个真实来源、至少两个假生成器的训练与校准结构。
- 优先来源平衡 ERM、普通增强和相对响应；这些是必须超过的简单基线。
- 只有域标签可辨识、跨域同类别有足够样本时，才把类别条件来源对抗列为附加对照。
- 不把外部假视频标签用于部署，也不使用最终确认集来拟合域分类器。
- GRL、SNN、Transformer、时空 tube 均不自动进入主模型。

## 5. 数据角色和实验公平性

| 已查看的 ComGenVid 视频及同祖先视频 | 来源外开发、失败诊断 | 禁止重标为未查看最终集 |

| 新 OOD 开发池 | 额外真实来源、至少两未参加拟合的生成器 | 不能仅随机切分相同来源；两生成器统计共享真实组抽样 |
| 最终确认池 | 方法锁定后一次性确认 | 与所有已接触视频的祖先隔离；身份与访问记录冻结 |

起步规模：训练/校准总计约 2400 条合格视频，OOD 开发约 900 条（300 真、两个生成器各 300 假）。这是运行目标，不是已获数据；数据不足时先完成机制诊断，不复制样本补配额。

旧 4 fps/128 像素轨道先作回放；新 8 fps/224 像素轨道单独冻结采样器和缓存。精度、裁剪、插值核或光流改变时，所有比较臂一起重算。

JPEG70 是裁剪缩放后的逐帧压力检查，不是真实转码。新传播实验先对整视频变换再抽帧，真实平台上传下载另列。

已有多个 MSVD clip 来自同一 YouTube 祖先；推断出的祖先仅用于保守分组，未知关系继续标记 unknown。最终独立性还需要跨来源内容检查。

## 6. 比较矩阵与近期文献边界

| 层级 | 必做比较 | 隔离的问题 |
|---|---|---|
| 统计基线 | correct、fractional、correct+fractional、correct+wrong、duplicated-correct | 额外信息、维度和普通拼接 |
| 最小方法 | 单对照差分、多对照差分、H1 归一化 | 各算子是否必要 |
| 强表征 | 冻结 DINO + LR/MLP、DINO + 普通对齐、DINO + H1 | 是否超过语义表征和普通融合 |
| 外部算法 | D3、STALL，随后 ReStraV/WaveRep | 与相关公开方法的实际差距 |
| 处理排假 | 共同 mask、固定内部区域、插值核切换、另一光流实现 | 是否仅仅检测预处理指纹 |
| 学习排假 | 来源平衡 ERM、普通增强、容量匹配编码器 | 是否来自训练规模或参数量 |

2026-09-14 核对官方来源：

- [D3](https://github.com/Zig-HS/D3)：免训练二阶特征检测，列入时间统计基线。
- [STALL](https://github.com/OmerBenHayun/STALL)：空间/时间似然与真实集校准；官方提供 ComGenVid 预计算表征入口，可先做来源相同、样本 ID 相同的低成本参考。预计算表征不能输入我们的光流流水线；它属于作者原生轨道，不能冒充相同骨干/预处理的公平消融。
- [光流残差与时空一致性先例](https://arxiv.org/abs/2508.00397)：已有外观与光流残差结合的工作，须逐项核查任务、算子和损失，不能把二者拼接称为首创。
- [WaveRep 官方仓库](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection)：作为增强方向对照，复现状态仍为未完成。

2026-09-15 新证据：STALL 在完整 ComGenVid 上 AUROC 0.85245，在与我们相同的 150 个 ID 上为 0.82280；我们的冻结融合为 0.60560。该结果明确指向跨来源表征差距，且由于骨干、预计算方式和采样路径不同，仅作原生协议参考。下一轮优先级从“继续调融合权重”改为“建立 DINO/原生帧的共同表征对照，再测试来源平衡与受控对应响应”。

同日真实锚点校准筛查也未形成候选：用外部 50 条 MSVD 真实样本估计均值/尺度后，绝对偏差的 AUROC 约 0.50；把锚点特征加入内部拟合得到 0.6298。该结果使用已查看外部开发池，仅作方向筛查，不释放 GPU 训练；锚点本身不能替代跨来源表征学习。

这是定向先例核对，不是完整新颖性审查。官方表格与本地 150 条结果不可跨协议排名；第二阶段应保存 commit、环境、原生参数和失败复现。

## 7. 放行条件

仅在尚未查看的新 OOD 开发结果前冻结以下探索门槛；目前不是结果，也不是 CCF-A 录用标准。

1. H1 对预先确定的最强简单/强表征对照：macro AUROC 增益至少 0.03，来源祖先分组配对 95% CI 下界大于零。
2. 两个 OOD 生成器的增益方向一致；最差组不得下降超过 0.01。
3. clean AUROC 不下降超过 0.01；至少一个预先留出的整视频退化条件增益为正。
4. 对有随机性的编码器运行五个冻结 seed（17/29/43/59/71），至少 4/5 为正；确定性 LR 仅报告一次，并用分组统计衡量不确定性。
5. 强基线、同容量对照、mask/来源排假和全链路 p50/p95 延迟齐备。编码器主比较暂以额外端到端延迟不超过对应基线的 25% 为工程目标，实际以 profile 修订后冻结。

探索通过后仅选择一个候选进入最终确认；最终确认使用原总计划的更完整门槛（宏平均、最差组、多个未见生成器及新真实来源），不得选择性只报告通过的子组。

若方法仅仅在内部提高：停止扩容，完成失败解释。若仅跨来源有效但没有相对强基线的算法增量：保留诊断发现，暂缓 CCF-A 方法论文。若 H1/H2 均失败：记录转向，不强加 SNN。
