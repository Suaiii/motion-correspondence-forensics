# AL47：零假设探针与实际读出功效的最小区分设计

2026-09-19，planagent。状态：设计草案，未执行、未选 probe、未授权真实批次。输入 AL12、AL19、AL35、AL43；只写可否证边界，不运行模型/媒体/训练/服务器。

| 零假设/失败情形 | 必须冻结的量 | 只能排除/尚不能支持 |
|---|---|---|
| 同一个确定性完整 probe，或已证明软算子P_a/P_b在该域可交换 | R_a/R_b 与 P 定义、缓存复位、顺序和共同支持 | 预期K=0是正确null；非零才提示实现/缓存或前提失败。两个非线性原R可交换不自动认证其软混合P可交换 |
| clip/缓存/边界造成伪次序 | dtype、裁剪率、cache reset、槽位映射、输出范围 | 排除部分处理伪影；不证明非线性真实机制 |
| K 非零但 q/固定头盲 | K、四个 q、w*q、分子/分母变化 | 说明场变化不传给读出；不能把 K 非零当来源增量 |
| q 被稳定完整头包含 | P 选择矩阵、诱导正则、同调用成本 | 排除“新增信息”说法；仍可检验有限归纳偏置 |
| R/G 同处理但跨来源失效 | origin/processing 双标签、祖先、decoder、传播链 | 关闭来源主张；不切换标签保住结果 |
| 未见 decoder/source 失效 | 组件身份、留出规则、覆盖率和 fallback | 关闭迁移主张；不得重命名开发池 |

预注册前固定 probe、h、eta、滤波、支持和分数方向；禁止看 audit 后扩充 bank 或改参数。若兼容性任一项失败，保存结果并停止该候选执行；若兼容性通过，仍需独立数据/预算/科学准入和强基线门槛。条件表只区分哪些解释可被排除，不增加信息量或授权任何 GPU/媒体调用。

未来最多执行一个小型兼容性检查包，内容为已绑定 wrapper 的算子合同与固定 null 对照；必须与有标签机制批次分离，声明调用成本和停机安排。当前未绑定实际 wrapper/权重/样本，保持 unknown。

执行与选择的边界：相同probe的零对照是在原算子身份和精度政策下检查实现，预期零通过不等于预定候选probe对有判别功效；预定候选对本身若在全部合法输入恒为零，只说明该对在此构造下无信息，不允许看标签后替换更有利的probe并沿用原协议。通用非线性R的交换性须另核对软P，不能套线性矩阵结论。

删除重复验收项：AL32已检查的三场共享q、AL29的包含矩阵与AL16误差界不在新包重跑；继承其限定证据。新增兼容性必须绑定实际wrapper、权重和数据/资源条件才有信息价值；条件未齐备时不把完成表格计成模型通过。R/G标签、来源外与未见decoder项留在后续有标签机制批次，不能混进仅兼容性profile宣布效果。

没有实际误差上界时，同probe两条路径差仅可记经验数值诊断；重复为0不证明误差为0。对照阈值须根据预先数值政策声明，不能从新标签结果调到通过。与现有AL35重叠的来源/资源字段直接引用，避免重复扩写成新贡献。
