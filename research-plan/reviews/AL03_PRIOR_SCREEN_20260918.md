## H-J的一个可证区别

令X/Y/Z均为均匀正负1变量，三个相关系数为r_ab、r_bc、r_ac。合法两帧分布为
Q(r)=[[1+r,1-r],[1-r,1+r]]/4。共同可实现性由经典相关多面体的四个不等式描述：

    1+r_ab+r_bc+r_ac >= 0
    1+r_ab-r_bc-r_ac >= 0
    1-r_ab+r_bc-r_ac >= 0
    1-r_ab-r_bc+r_ac >= 0

在固定[-1,1]网格上的125种组合中，小型LP与相应平均L1距离的解析表达逐项相符。
r=(0.5,0.5,0.5)存在共同联合分布，H-J距离为0，但条件转移矩阵连乘的JS为0.00913718。
r=(-0.5,-0.5,-0.5)每对都合法，却不能共同实现，H-J距离为1/6。
这证明两种量对构造的歧义例子可作不同判断，不证明真实视频检测优势，也不把经典多面体视为原创。

## 静态核的零缺陷推导

对同一组单位特征z_i，令K_ij=exp(z_i^T z_j/tau)，tau>0；取正的对称缩放d使
Q=diag(d)Kdiag(d)满足声明的单点边际，总质量1。设G为标准高斯变量，

    phi_i(G)=exp(z_i^T G/sqrt(tau)-||z_i||^2/(2*tau))
    u_i(G)=d_i*phi_i(G), S(G)=sum_i u_i(G)

高斯矩母函数给出E[u_i u_j]=Q_ij。由于S>0，定义

    Gamma_ijk = E[u_i u_j u_k / S]

则Gamma非负，求和消去任一维后都得到Q，总质量1。因此完整支持、完全相同特征集、
同一对称正缩放下的三个两帧Q共同可实现，H-J理论值为0。将每帧一致地重排索引，
对应重排Gamma即可保持可实现性。全局核缩放常数不改变平衡后的Q。

这是本轮提出的适用条件推导，仍待不同复核者检查。它不是对真实DINO等变性的声明，
不覆盖遮挡、缺失质量、不同支持、独立变形或任意特征变化。置换零缺陷也意味着：
仅靠这个量无法检测保留特征身份但几何上不合理的任意重排；运动/物理主张需要额外可观测量与对照。
