# AL29：直接保留候选能量的紧凑基线坐标

2026-09-19，planagent。基于已审AL20/AL25，仅推导坐标与度量；没有重跑七个场、拟合模型或改变OR1-readout-1。设计目的在于避免用消去较差的基线制造表面优势，不将坐标变换称为算法创新。

## 1. 候选特征应直接包含在基线中

对同一个空间滤波、共同支持和同一正分母D，令a=d_a、b=d_b，s=a+b，k=a-b。定义

    r_S = mean(Hs)^2 / D,
    r_K = mean(Hk)^2 / D,
    r_J = mean[(Hs)(Hk)] / D.

候选q就是r_K。未来实现应复用候选已计算的HK、N、D或q值，不再通过两个大能量及内积的相减重建它。AL25已验证的近抵消记录中，直接q约1.38778e-17而raw compact为0；保留原记录，这一差异不能计为新增来源信息。

若将来真实四调用核心采用另一个K计算次序，应先固定该数值政策，并让基线复用同一个候选K/q。端点差与交叉增量差在实数中等价，有限精度下不能无记录地混用。

## 2. 实数中的可逆关系

对原z=(A/D,B/D,C/D)，有r=M z：

    M = [[1, 1,  2],
         [1, 1, -2],
         [1,-1,  0]],

    M^-1 = [[1/4, 1/4,  1/2],
            [1/4, 1/4, -1/2],
            [1/4,-1/4,    0]].

即A/D=(r_S+r_K+2r_J)/4，B/D=(r_S+r_K-2r_J)/4，C/D=(r_S-r_K)/4。det(M)=-8，两个逆乘积均为I；这是同信息坐标变换，不增加输入。

这个关系不意味着能从已经舍入的旧z恢复丢掉的小量。稳定提取需要原有响应场/候选K，必须在能量压缩之前得到r_K；仅对旧三元组做矩阵乘法不能修复信息丢失。

## 3. 正则必须随坐标一起变换

原自由基线分数beta^T z改写为gamma^T r时，beta=M^T gamma。为了保持AL20的自由目标，平方惩罚应是

    (lambda/6)||M^T gamma||²
      = (lambda/6) gamma^T G gamma,
    G=M M^T=[[6,-2,0],[-2,6,0],[0,0,2]].

G的特征值为2、4、8，正定。四个滤波使用该矩阵的分块对角扩展，不混用四个滤波的分母或支持。

每个滤波取gamma=(0,w,0)，则beta=(w,w,-2w)，数学分数与候选相同；其惩罚为lambda*w²。四组求和恢复原四权重惩罚。因此稳定坐标下的自由12参数族仍包含候选及其同惩罚子空间。

换坐标后若任意使用相同字面系数的各向同性||gamma||²，就改变了自由基线的目标。可以另定义这样的实验，但不得称它与原基线仅是数值重排。AL27当前冻结的是原z与lambda/6目标，本报告不修改或重跑该任务。

矩阵和嵌入均用Fraction核对，见[精确证据](AL29_COORDINATE_MATRICES_20260919.json)。本轮没有执行r的张量实现或新的数值优化。

## 4. 数值与科学限制

共享r_K=q确保该特征值直接可用；任意12项dot与4项dot、不同求和顺序或优化器仍不自动bitwise一致。若要检验约束对照的逐值一致，应使用相同q提取、相同四项评分与损失代码，并另外报告自由头的数值差。

这种构造不能消除probe/端点误差，不能恢复已丢掉的原始响应，也不防止overflow或证明真实AE的误差界。sum/difference场和r_J的计算也须记录精度及代价；多出的算术/滤波不能隐藏，但不需要新增AE调用即可使用已有响应场。

后续公平比较应同时记录：选用的K计算政策、共享q、raw和稳定坐标、分母/支持、诱导正则、数值停止规则、实际算术成本与coverage。实际模型/数据/分类效果均未验证。

AL29按 `stable_baseline_coordinate_contract` 完成数学审查。剩余可检验价值依然是受约束读出的真实泛化，而不是击败数值上较差的A+B-2C路径；创新、资源及最终集门槛保持不变。
