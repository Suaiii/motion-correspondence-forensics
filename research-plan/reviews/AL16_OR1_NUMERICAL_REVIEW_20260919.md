# AL16：OR1的误差放大与无信息域

2026-09-19，planagent独立于AL15实现的数学审查。只采用a4cfdeb的OR1公式；
没有执行AE、媒体、GPU、训练或改变AL15冻结输入。本文件的界均有显式前提，
真实误差和Lipschitz常数未知时不产生数值安全证书。

## 1. 先区分三类误差

- 代数截断：有限h的K_h与局部交换项J_va v_b-J_vb v_a之差，在给定平滑性下为O(h)。
- 计算误差：同一个固定h目标在有限精度、近似probe、缓存或其他实现下的误差。
- 统计/模型误差：该特征是否预测来源、阈值的有限样本误差以及域外泛化。

降低h可能降低第一项却放大第二项，不能据此优化第三项；以下仅约束第二项。
所有范数采用同一支持上RMS范数，或统一采用Euclidean/Frobenius范数；
不得在同一个界中混用sum和mean尺度。原始解码、传输或codec改变数据本身，应另作处理链效应。

## 2. 端点误差界

设精确端点为u_ab、u_ba，实际端点分别满足||hat_u_ab-u_ab||<=delta_ab、
||hat_u_ba-u_ba||<=delta_ba。最终减法/除法额外误差界为rho_K，h准确取预定值，则

    ||hat_K-K_h|| <= (delta_ab+delta_ba)/h² + rho_K = B_K.          (N1)

这是三角不等式，未假定误差独立或会相消。端点误差未知，不能把右侧填0。
N1不需要C²；N2另外要求所列Lipschitz前提。平滑性不足会限制局部交换项解释，但不自动否定有限h响应的定义。
确定性重复两次相同，仅排除了部分随机性；相同舍入偏差、低精度偏置会在两次输出中重复。
预定h为二进制可精确表示的值，也不消除probe与端点的误差。

## 3. 从单次probe误差传播，不能混淆误差层级

设0<h<=1，R_j在包含实际/理想路径的邻域内Lipschitz常数L_j已知。
P_j^h的常数可取ell_j=(1-h)+h L_j。令epsilon_j^(0)为第一层R_j调用误差，
epsilon_a^(b)、epsilon_b^(a)为第二层调用误差；rho表示对应混合算术的误差，则

    delta_a <= h*epsilon_a^(0) + rho_a,
    delta_b <= h*epsilon_b^(0) + rho_b,
    delta_ab <= ell_a*delta_b + h*epsilon_a^(b) + rho_ab,
    delta_ba <= ell_b*delta_a + h*epsilon_b^(a) + rho_ba.             (N2)

其中第一项比较同一个理想外层P在被扰动输入上的变化，第二项是外层probe自身近似误差。
必须对两个不同输入处的调用都给有效界，不能把单点重复实验等同整个邻域的L_j证明。
如果所有probe误差<=epsilon、L_a,L_b<=L、忽略混合及末端算术误差，N1/N2给出

    B_K <= [4/h + 2(L-1)] * epsilon.                              (N3)

这里的主要放大为O(epsilon/h)，因为probe误差先乘h；
直接把“单次probe误差”代入“端点误差”会混淆含义。混合算术rho不一定先乘h，仍可能按h^-2放大。
ReLU边界附近、clipping、状态缓存或随机过程会改变所需假设；L_j未知保持unknown。

| h | 每单位端点误差的h^-2 | 两端各delta时系数 | L=1且各probe误差epsilon时系数 |
|---|---:|---:|---:|
| 1/4 | 16 | 32 delta | 16 epsilon |
| 1/8（主值） | 64 | 128 delta | 32 epsilon |
| 1/16 | 256 | 512 delta | 64 epsilon |

这些是固定公式的放大系数，不是实测float32/float16误差，也不支持事后选最有利h。

## 4. 滤波能量和比值

H_l必须是含具体边界策略的固定线性算子，设其诱导范数有已知上界L_Hl。
令z_l=H_l K_h、hat_z_l为实际结果，||hat_z_l-z_l||<=B_zl，
其中可用B_zl=L_Hl B_K+rho_Hl。不能只看卷积核名称就假定所有padding实现有相同范数。

由平方范数展开可得，分子n_l=||z_l||²的可计算误差界为

    B_Nl = 2||hat_z_l||*B_zl + B_zl² + rho_Nl.                    (N4)

同理计算单步残差滤波能量e_al、e_bl的误差界，求和再计入算术误差得到B_Dl，
使真实d_l=e_al+e_bl+eta与实际hat_d_l满足|d_l-hat_d_l|<=B_Dl。
eta的数值表示属于固定实现或其误差记录，不等于噪声已被控制。

如果hat_d_l-B_Dl>0，则把商写为两项差并用分母下界，可得

    |hat_q_l-q_l|
       <= B_Nl/(hat_d_l-B_Dl)
          + |hat_n_l|*B_Dl/[hat_d_l*(hat_d_l-B_Dl)] + rho_ql.       (N5)

若未来实现严格认证，右端量本身也须使用有效上包络或向上舍入；普通浮点直接代入只能标作经验估计。
不满足正的分母下界、误差界不可估或分母主要由eta支配时，应报告不稳定/无信息/未认证状态，
不将低分或q=0自动判真。不得假定真值K非零来使相对误差看上去更小。
如果未来需要数值拒绝阈值，应在查看真假结果前根据误差与量纲另行冻结；本审查不修改当前eta或例子。

固定线性权重w下，分数误差界可取sum_l |w_l|B_ql+rho_s，rho_s应包含有关cast/求和误差。
若与固定阈值的间隔超过这个界，只能支持该数值实现下决策符号稳定；
它不证明来源判断正确，也不覆盖模型、训练、阈值估计或分布漂移的不确定性。

## 5. 后续profile需要记录的字段

记录input/output dtype、每次R调用的计算精度和posterior策略、cache reset、
每个h的端点及K范数、分母分解、eta占比、重复差、与更高精度参照的差、
各误差界的来源和是否仅为经验估计、coverage状态与原因。
若使用Lipschitz界，记录其成立域和证明/估计方法；经验局部斜率不充当全域上界。
额外重复或高精度调用单列成本，不能加在主推断路径里仍声称总量4。

低精度和高精度结果相近是有用工程证据，但高精度参照也不一定是数学真值；
未建立严格界时标签应为empirical_precision_check，不能写certified。
按来源/decoder/处理链报告覆盖，避免数值拒绝本身泄漏类别。

AL15当前float64、固定小向量和mock通过，仅验证该环境/输入的软件性质。
真实视频AE的FP16/BF16/FP32安全性、完整四滤波读出和真实覆盖均未验证。
AL16可按numerical_error_contract范围结项；不解锁模型/媒体/预算或候选创新门槛。
