# AL51：有限软路径包含原次序差与插值弦偏离

2026-09-19，planagent。仅符号机制审查；没有数值批次、AL49回放、真实样本、模型或服务器调用。本报告检验工作单中的等式并给出成立条件，不修改原OR1算法或把普通代数称为原创贡献。

## 1. 作用域与完整映射

令R_a、R_b是同一实向量空间中的确定性完整重建映射，所有调用从声明的相同缓存/随机状态开始。输入u、R_a(u)、R_b(u)、沿两个输入—重建弦的点，以及两项完整复合都须在合法定义域内；输出采用同一网格、坐标、颜色范围和支持。这里分析的是两个公开探针，不能把它们的复合命名为未知生成器的真实历史处理顺序。

固定0<h<=1，令a=1-h，P_j(u)=a*u+h*R_j(u)，K_h=[P_a(P_b(u))-P_b(P_a(u))]/h²。定义

    C = R_a(R_b(u))-R_b(R_a(u)),
    J_a = R_a(P_b(u))-a*R_a(u)-h*R_a(R_b(u)),
    J_b = R_b(P_a(u))-a*R_b(u)-h*R_b(R_a(u)).

J是沿弦非线性映射与端点线性插值之间的偏离；向量值的J没有一般的正负性，不因为名称就假定凸性。C和J都未被真实模型测量。缓存、类别依赖条件或尺寸变化若使每次调用不再是同一映射，下面等式不自动成立。

## 2. 精确有限h分解，不需要可微性

先展开最外层的软步，保留内层非线性：

    P_a(P_b(u))-P_b(P_a(u))
      = a*h*(R_b(u)-R_a(u))
        + h*(R_a(P_b(u))-R_b(P_a(u))).

将J的定义代入括号：

    R_a(P_b(u))-R_b(P_a(u))
      = a*(R_a(u)-R_b(u))+h*C+(J_a-J_b).

两个a*h项抵消，因此

    P_a(P_b(u))-P_b(P_a(u)) = h²*C+h*(J_a-J_b),
    K_h = C + E_h,       E_h=(J_a-J_b)/h。

这是原定义的代数恒等式，前提是所有映射调用合法且一致；不依赖Taylor、Lie群或正交性。非光滑映射也可满足此恒等式，但下面的曲率界另需光滑前提。若h=1，J_a=J_b=0，K_1=C。若h=0，两条软路径都为u，但K_h是0/0，不能赋值0；右极限需要另行推导。

## 3. 曲率界必须覆盖完整弦

记v_b=R_b(u)-u、F_a(t)=R_a(u+t*v_b)，0<=t<=1。在固定输出范数下，若F_a二阶连续可微，则两次积分给出精确的插值余项

    J_a = -(1-h) integral_0^h t F_a''(t) dt
          -h integral_h^1 (1-t) F_a''(t) dt。

若沿这条完整弦有 ||D²R_a(u+t*v_b)[v_b,v_b]||<=M_a||v_b||²，则

    ||J_a|| <= h(1-h) M_a||v_b||²/2。

对F_b(t)=R_b(u+t*v_a)同理。这里M是相应输入/输出范数下的导数界，不混用sum和mean尺度。于是

    ||K_h-C|| <= (1-h)/2 * (M_a||v_b||²+M_b||v_a||²)。

虽然J为O(h)，J/h一般仅为O(1)；降低h并不保证插值项相对C消失。这个界需要从u一直到R_b(u)或R_a(u)的整条弦，不只是u附近的小球。完整弦可能跨越ReLU/clip区域，真实M未知；不能把经验局部斜率填作全弦上界，也不能因代数分解成立就宣布该界已认证。

## 4. h趋近0时各项如何组合

若R_a/R_b在u可微，完整端点值仍固定，则

    J_a/h -> DR_a(u)v_b + R_a(u)-R_a(R_b(u)),
    J_b/h -> DR_b(u)v_a + R_b(u)-R_b(R_a(u))。

加回C后完整复合项抵消：

    lim_(h->0+) K_h
      = DR_a(u)v_b-DR_b(u)v_a+R_a(u)-R_b(u)
      = Dv_a(u)v_b-Dv_b(u)v_a。

这与AL12的局部向量场交互相容，但它不等于一般非线性映射的完整C。若R_a/R_b为仿射映射，弦插值准确，J_a=J_b=0，所以全部合法h均有K_h=C。对R_a(u)=Au+c_a、R_b(u)=Bu+c_b，

    C(u)=(AB-BA)u+(A-I)c_b-(B-I)c_a。

仿射情况下，仅A/B矩阵可交换仍可能因偏置项有非零C；需要完整仿射映射可交换。线性零偏置情形才可直接用AB=BA。一般非线性原R可交换只令C=0，剩下E_h仍可非零，符合AL49的限定数学问题；本轮没有重跑或恢复其失败执行合同。

## 5. 分解向量能量，保留有符号交叉项

对同一滤波H_l、共同支持内积和原OR1正分母D_l，令c_l=H_l C、e_l=H_l E_h，则

    q_l = (||c_l||²+2<c_l,e_l>+||e_l||²)/D_l。

完整次序项与弦偏离项的能量不是简单百分比分摊：交叉项可负、可抵消，两项均非零仍可能K为0。C主导、E主导、抵消或协同均需分别观测，不能只比较两个正能量就宣布来源归因。沿用同一个D_l才能形成此分解；更换归一化分母是另一个统计量。

这细化H-OR待证预测：若未来标签相关变化只在E_h或交叉项中，支持的至多是软混合后的非线性响应，不能宣称已观察未知生产解码器的原始次序痕迹；即使变化主要在C中，也仍可能是内容、裁剪、探针选择或其他处理历史所致。原强匹配基线、静态/增强/来源/采样及未见组件要求全部保留。
