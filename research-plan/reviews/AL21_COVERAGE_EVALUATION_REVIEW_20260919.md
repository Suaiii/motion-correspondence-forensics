# AL21：OR1拒绝状态与完整评价人群

2026-09-19，planagent；独立于AL18数值合同实现。结论：数值拒绝和训练匹配会改变被评价的人群，必须明确每个指标的分母。接受子集上的更高AUROC不能直接满足完整研究目标的增益门槛。

## 1. 相同类别保留率仍可提高条件AUROC

以下分数及辅助变量z在计算前固定，接受函数为A(u)=1[z=0]。它在应用时不读取标签。没有模型调用、学习或参数选择；这些数字仅为评价公式反例，不是OR1预测。

| 样本 | 假想标签 | 固定分数 | z | 是否接受 |
|---|---:|---:|---:|---|
| p_hi | 1 | 9/10 | 0 | 是 |
| p_low | 1 | 2/5 | 1 | 否 |
| n_hi | 0 | 3/5 | 1 | 否 |
| n_low | 0 | 1/10 | 0 | 是 |

全部四个正负对的赢分分别为1、1、0、1，完整AUROC=3/4。接受后仅剩(p_hi,n_low)，条件AUROC=1；两类覆盖率均1/2。分数和排序规则都未改变，评价子集的改变已足以产生1/4的表面差异。故按类覆盖相同、接受函数不直接读取标签，都不能保证选择后与原人群可比。

固定阈值1/2下，完整表的FPR=TPR=1/2；接受集FPR=0、TPR=1。若被拒绝样本没有后续决策，不能把后两项称为完整系统的FPR/TPR。逐对精确分数与分母见[输入](AL21_FIXED_ILLUSTRATION_20260919.json)、[回执](AL21_COVERAGE_EXACT_20260919.json)、[枚举器](audit_al21_coverage_20260919.py)。

## 2. 未评分样本造成的可识别范围

对于固定合格测试池，使用均匀的全部正负样本对，并给分数相等1/2的赢分。设正/负类接受比例c_+、c_-，接受集条件AUROC为a，则接受的正负对仅占p=c_+ c_-。对任何延伸到被拒绝样本的完整标量评分，均有

    p*a <= AUROC_complete <= p*a+(1-p).

证明仅使用每对赢分在[0,1]内；已观测接受对的总贡献为p*a，其余对的总权重为1-p。在上例中区间为[1/4,1]，并未确定完整表现。若方法本来不对拒绝样本输出分数，这个区间只是允许的完整评分延伸范围，不意味着已经产生了一个完整检测器。

该式针对所声明的全交叉对和均匀权重。若采用祖先权重、排除特定配对或其他指标，应用相应的接受对总权重，不能机械套用c_+ c_-。每生成器AUROC须分别定义池和对权重，再按预定规则宏平均。

在固定阈值下，令r_A为接受真样本中的FPR、c_0为真样本覆盖，则

    P(A=1且输出假 | Y=0) = c_0*r_A.

这是自动输出假这一联合事件率。若拒绝样本最终被后续系统判假的比例为r_R，则完整FPR=c_0*r_A+(1-c_0)*r_R；没有指定后续处理时，只得到[c_0*r_A, c_0*r_A+1-c_0]。TPR同理。把拒绝一律当真会隐含指定一个决策策略并损害漏检表现，不能静默这样填充；转人工也不能把未知结果当成功。

## 3. 给OR1比较的具体合同

先冻结与方法无关的数据合格性规则和目标测试池，单独报告原池到合格池的排除数；在该合格池中，记录每个方法的数值/支持接受状态、原因和实际输出。模型自己的拒绝不能追写为数据原本不合格。

至少区分下列评价对象：

1. **接受集条件结果。** 报告该接受集合的ID/摘要、各类/来源/生成器/处理链覆盖、条件AUROC与条件阈值指标；无正或无负时AUROC未定义，不能填0.5或删除该生成器后重新宏平均。
2. **共同接受集诊断。** 在两个方法都接受的同一输入上配对比较；这提供该交集上的比较，仍不能代替完整目标池。仅匹配总体覆盖比例不足以保证两个方法接受同一批输入。
3. **完整系统结果。** 如要使用完整目标池的原宏增益门槛，须先冻结拒绝后的可执行路线及评分/阈值规则，再在全部合格输入上评估。回退分数与主分数未必可直接比较，其校准只能在独立校准池拟定；不能临时把拒绝分数设0、删掉或按测试标签补齐。

若选择升精度重算来处理拒绝，应把额外AE调用、条件触发、覆盖和最坏成本一起定义；重算后的系统不能仍无条件声称每输入总四次调用。若维持纯拒绝，则报告风险与覆盖这一目标，不能在没有批准改写研究目标的情况下用条件高分替代原0.03宏增益门槛。

coverage应按多个分组报告，并保留support-only/拒绝指示对照。拒绝与来源相关本身不证明检测算法学到了来源机制。阈值、eta、h、误差容限和共同支持规则均不得根据留出测试标签调节。

## 4. 训练匹配和推断拒绝是两个选择过程

AL12的caliper和同D同k配对发生在训练构造中，改变的是训练分布及损失的权重；它不证明原始摄像C或未匹配来源被覆盖。推断数值拒绝则改变有预测值的人群。两者需要分别登记，不能把“训练配对成功”当所有测试样本有共同支持。

匹配只使用预定b、训练统计及必要分层字段，不使用q或测试结果，仍不构成条件独立或无混杂证明。AL13明确的祖先关系和真实数据来源审核也不能由匹配或数值状态代替。

## 5. 配对区间和已有文献的边界

方法比较必须在相同目标池、相同派生处理版本上形成配对单位；完整祖先连通组是重采样单位，不把同祖先派生版本或AUROC中的所有交叉对当独立样本。共享真实视频的多个生成器比较，在同一bootstrap复制内复用同一真实祖先抽样；种子平均差、单种子差和集成分数差分别定义，不能混用其区间。

自有接受掩码固定后，条件指标的抽样区间仍只针对其条件目标；正的区间下界不解决目标人群改变。某个复制中某类为空时保留无效原因和可估范围，不用随意填数制造稳定区间。实际重采样和样本量设计尚未实施，本报告不提供真实置信区间。

拒绝选项与风险/覆盖的联合报告已有明确文献基础：[Geifman与El-Yaniv，Selective Classification for Deep Neural Networks，2017，§2](https://arxiv.org/html/1705.08500v2#S2)。该文把选择函数、覆盖和接受后风险分开，并在相应同分布抽样假设下讨论风险控制。这里的四分数反例与AUROC/阈值分解是本次直接推导；没有把该文的保证外推给OR1或有关联的视频祖先样本。
