# 当前候选的近邻与替代解释审查

日期：2026-09-17；角色：planagent。用于 RS01 和下一轮机制协议讨论，不代替科研端完整精读，也不代表已完成新颖性审查。

## 新增直接近邻

[Jabri、Owens、Efros，NeurIPS 2020：Space-Time Correspondence as a Contrastive Random Walk](https://proceedings.neurips.cc/paper/2020/hash/e2ef524fbf3d9fe611d5a8e90fefdc9c-Abstract.html) 已将视频 patch 作为时空图节点，以特征相似度构造随机游走转移概率，用多步路径表达长程对应，并以返回起点的循环约束学习表征。还研究了 edge dropout。

这意味着“patch 相似度—转移矩阵—路径组合”并非本项目新提出。当前候选与其不同的拟议部分是：冻结表征上的直接/两步差异及同视频单侧置换响应，用作取证读出，并在来源、静态与采样对照下证明增量。这个差异目前仅是待验证问题。

检索核验范围：官方会议摘要及 [arXiv v2 HTML 的第2节](https://arxiv.org/html/2006.14613)。会议 PDF 的网页提取因文件过大失败，随后已通过作者论文 HTML 核对：式(1)为归一化特征内积的逐行温度 softmax，式(2)为转移矩阵连乘。本项目对应构造与这两步有直接继承关系。训练细节和数据协议的完整逐项比较仍由 RS01 完成；不把局部精读写成全面查新。

附录 C 还讨论了单张 feature map 路径中的位置/边界捷径；附录 D 使用同一图像反复出现的时间序列作静态对照。因此本项目的静态控制属于必须做好的一项实验控制，也不应单独列为创新贡献。

## 需要在机制协议中回答的问题

1. 非零直接/两步 JS 可能来自软转移本身的扩散效应；静态反例已在本项目复现，不能仅凭数值非零建立时间异常主张。
2. 六帧静态 patch 基线必须保留相同帧内容与全局语义输入，不能只保留一帧后把信息量差异当作时序收益。
3. 单侧置换与一致重编号必须区分；位置、图边界和中间支持概率质量需要对照。
4. 新采样的三元组要检查联合实际间隔，旧缓存一个0.5秒帧对并不充分。
5. 即使有来源外增量，仍须比较普通增强、容量和直接近邻，才能确定新颖性强度。

## 建议提交给协议冻结阶段的便宜比较

在相同冻结 DINO 对应矩阵上，可先定义二步返回概率和三角返回概率的简单统计，分别由 P_ab P_ba、P_ab P_bc P_ca 的对角量构造，作为经典循环一致性启发的探针。其用途是检验复杂扰动响应是否超过简单循环分数。

这两个式子是本审查提出的对照建议，不是对 CRW 作者实现的复现声明。需由 RS01 完成全文比对后，在 RS07 的冻结协议中确定是否纳入、具体聚合与计算预算；不能在看过机制审计结果后选择有利定义。

## 当前决定

维持 v1.1 主候选与门槛，先完成 DX01 的静态对照准备与联合时间支持可行性，保留负结果。没有现阶段证据支持把本项目称为突破，也没有依据仅因静态反例而直接否定最终检测可能性。
