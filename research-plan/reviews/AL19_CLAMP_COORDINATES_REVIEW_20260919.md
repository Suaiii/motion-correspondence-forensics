# AL19：范围夹断和像素坐标足以改变OR1响应

2026-09-19，planagent数学审查；与AL18实现独立。采用AL12有限h定义，未运行AE、媒体、分类器或GPU。本报告给出可否证原解释的简单替代机制，不判断真实数据上的主要成因。

## 1. 即使两路同样夹断，也能从可交换平移产生响应

在共同域[-1,1]上设C为范围夹断，a=1/4：

    R_a(x)=C(x+a), R_b(x)=C(x-a),
    P_j(x)=(1-h)x+h R_j(x),
    K_h(x)=[P_a(P_b(x))-P_b(P_a(x))]/h².

未夹断的两个底层平移可交换，其软步也可交换，K恒为0。
但固定x=1、0<h<1时，R_a(x)=1、R_b(x)=1-a，所以

    P_a(x)=1, P_b(x)=1-ha,
    R_a(P_b(x))=1, R_b(P_a(x))=1-a,
    P_a(P_b(x))=1-ha+h²a, P_b(P_a(x))=1-ha,
    K_h(1)=a=1/4.

所有R输出和软步中间输入仍在共同域内。两路均使用相同clip，并不能消除这个响应；因此“统一两路clamp”不是充分的机制排混条件。在该点v_a=0、v_b=-a，恒等滤波的比值为a²/(a²+eta)，仅仅范围处理即可得到接近1的值，尚未引入任何来源标签。

固定离边界控制x=0及h=1/4、1/8、1/16时，所有相关调用都未触发clip，K=0。上述边界例在三种h下均K=1/4，未夹断对照均0。全部12个固定路径算例及精确分数见[回执](AL19_CLAMP_COORDINATES_EXACT_20260919.json)，没有搜索或拟合。

此例不要求路径跨越不可微点：在x=1附近，R_a已经处于饱和的常数支路，R_b处于平移支路，局部可光滑且交换项也为a。故不能认为仅过滤“跨过kink”的样本就排除了clamp成因。一般边界附近的C²前提仍须另查，有限h定义本身不要求C²。

AL17发现具体SDK的两路末端clamp不对称，本例进一步说明：即使以后采用对称clamp，仍必须审查这个普通替代解释。本报告没有证明实际视频特征已被clamp解释，没有否证OR1相对完整强基线的全部可能增量。

## 2. 共同仿射坐标变换：K协变，固定eta比值不严格不变

设F(x)=s x+b，s非零，b为固定向量；同时将两个完整probe共轭为R'_j=F R_j F^-1，并使用同一h。于是

    P'_j(F(x)) = F(P_j(x)),
    K'_h(F(x)) = s K_h(x), v'_j(F(x)) = s v_j(x).

若H_l为同一固定齐次线性滤波算子（含相同的边界规则），N_l、D_l分别为K与两个残差的滤波平方能量，则

    q'_l = s² N_l / (s² D_l + eta')
         = N_l / (D_l + eta'/s²).

只有相应地取eta'=s² eta，才能在这组前提下保持原比值。固定eta使尺度变化留下有限差异；与AL15维度补零导致mean尺度变化的现象不同，不能混称。同一共同仿射映射的偏移b在残差/端点差中抵消；若滤波含非零常数填充等非齐次处理，须单独核查，不能仅凭滤波名称套用。

这要求完整probe、clamp阈值、输入输出约定一起共轭。只改变输入RGB范围而保持checkpoint入口或末端clamp不变，不满足推导前提。对一般可逆矩阵M，K'=M K，但欧氏能量一般不按共同标量缩放；不据此宣称任意坐标不变。

## 3. 非线性坐标下，Euler软步通常不能直接共轭

在正半轴取F(x)=x²、R(x)=x+a。精确共轭R'存在，但

    P'_h(F(x)) = (1-h)x² + h(x+a)²,
    F(P_h(x)) = (x+ha)²,
    P'_h(F(x)) - F(P_h(x)) = h(1-h)a².

x=1、a=1/4、三个冻结h的差分别3/256、7/1024、15/4096，均非零。仅仅借用“交换项”或“几何”术语，不能把当前有限Euler组合当任意像素坐标不变量。未提出或运行另一种积分算法。

## 4. 对后续设计的具体约束

固定wrapper必须写清共同像素域、归一化/逆变换、范围检查与clip位置；改变任何一项都改变R及有限h目标。实际profile要分别记录两路及两个层级的饱和比例、相对阈值距离、单步残差、端点范围，并保留等信息强基线。饱和诊断不能作为事后删去困难样本的理由；覆盖变化须按來源与处理链报告。

对照设计须包含普通clamp/范围处理可产生的响应解释；若比较原生clamp与一致wrapper版本，须提前规定且分表报告，不以“修正”之名替换原始候选。不得根据本反例给真实/生成标签、调整h/eta、删去旧负例或宣告新机制成立。
