# AL42：缺类重抽不能静默丢弃后用其区间开门

2026-09-19，planagent。下面给出有限权重统计对象和缺失重抽的数学包络，补齐 AL37 的 invalid 处理边界。公式不宣称 cluster bootstrap 在本项目已具备95%频率学覆盖率；实际数据、祖先、训练随机性和重抽实现仍未验收。

## 1. 固定目标与共同权重

先指定一个传播条件下的一视频一评分单位。若同一视频有多个视图，应按预先固定的规则汇总为视频分数，或者分别报告条件，不能以视图数量暗中改变权重。令 S[m,s,i] 是方法 m、种子 s 对单位 i 的冻结分数；G 是固定评估的生成器集合，不在重抽缺组后缩小 G。

定义 psi(x,y)=1{x>y}+0.5*1{x=y}。生成器 g 的正类集合为 I_g^+，负类集合 I_g^-。原数据下每视频权重 a_i=1；如目标人群要求固定设计权重，须在开审计前另行绑定 a_i，并同步修改以下定义。未声明时不能临时改成每祖先等权。

全局视觉祖先图产生连通簇 c(i)，K 个簇包括所有方法、种子、类、生成器共用的单位。一个提议的非参数重抽为 W~Multinomial(K;1/K,...,1/K)。同一簇所有单位使用同一 W_c，重抽权重 w_i=a_i W_c(i)。对所有 m/s/g 只抽这一套 W，不分方法、种子或生成器独立抽共享真实簇。

    A[m,s,g;W] =
      sum_(i in I_g^+, j in I_g^-) w_i w_j psi(S[m,s,i],S[m,s,j])
      / [(sum_(i in I_g^+) w_i) (sum_(j in I_g^-) w_j)].

原统计取 W_c=1。主差为

    Delta[W] = (1/5) sum_s (1/G) sum_g (A[candidate,s,g;W]-A[baseline,s,g;W]).

固定 generator 等权1/G不随样本数或某次重抽改变。各组内部两类权重分别归一化；祖先重抽会改变组内样本构成，这与保持 macro 的组权重是不同概念。它不保证真实来源混合比例固定；若目标还规定固定来源权重，必须另行指定来源分层统计和权重，不能默认为“已控制来源”。

即使同一祖先跨多个生成器或两类，W_c 仍共用。若同簇有一正一负，经验边际 AUROC 的该项权重是 W_c²：这是这里定义的**视频边际排名统计**，不等于从独立祖先正负对构造的另一个目标。若科学目标要排除同祖先对，必须事前换明确定义，不能事后删项。簇重抽控制相关性不代表改变视频权重为簇等权。

共享完全相同的真实负类池和负类权重时，pooled 是组 AUROC 按正类总权重加权的平均；组权重相等才与宏平均恒等。分母与目标始终逐项声明。平均五个 AUROC 差和先平均五个模型分数再计算 AUROC 一般不等同。

## 2. 缺类事件和分位数包络

令 V 为全部预定 g 分母都正、全部预定方法/种子分数可用的事件。若缺类或缺组，Delta[W] 未定义；不得写0，也不把缺失组去掉后计算新的 macro。设 rho=P(not V)，F_V 是 valid 事件条件下 Delta 的分布。

Delta 是两个 AUROC 的差的均值，所以定义域内在[-1,1]。把 undefined 事件任意完成为这个范围内的值仅是一种敏感性分析：若完成分布为 H，则

    F(x)=(1-rho) F_V(x)+rho H(x),
    (1-rho)F_V(x) <= F(x) <= (1-rho)F_V(x)+rho。

上界由把所有缺失质量放在-1实现，下界由放在+1实现（内部 x∈[-1,1)）。对 Q(alpha)=inf{x:F(x)>=alpha}，rho<1且0<alpha<1 时：

    Q_lower(alpha) = -1                              if alpha<=rho,
                     Q_V((alpha-rho)/(1-rho))         otherwise;
    Q_upper(alpha) = +1                              if alpha>1-rho,
                     Q_V(alpha/(1-rho))               otherwise.

rho=0 时退化为 Q_V；rho=1 时没有 F_V，可行包络为[-1,1]。这是缺失分布完成下的分位数上下包络，**不是实际测得的置信区间，也不是总体覆盖率保证**。特别是 rho>=0.025 时，任意完成的2.5%左分位数下包络为-1；valid-only 正下界不能强迫完整分布下界为正。

唯一固定例来自事先工作单：rho=1/25，valid 质量24/25全部在 Delta=1/10。alpha=1/40 时，valid-only 分位数为1/10；把 invalid 完成为-1得到完整左分位数-1；完成为+1得到左分位数1/10。因此完整左分位数可行区间为[-1,1/10]。这仅是一张离散分布表，没有执行实际 bootstrap，也没有虚构原视频样本或研究 CI。实际有理数核验另存回执。

若将来仅做 B 次模拟重抽，B_invalid/B 是该次有限重抽的经验缺失质量，不是精确的真实 rho。上式可用于这张经验分布表的完成界，但不能再宣称消除了 Monte Carlo 误差。有效抽样比例的容许门槛、B、随机状态与分位数算法都应在正式协议冻结，本回合不从未知数据推造这些数值。

## 3. 科学门槛的处理提案

新协议建议默认 fail-closed：出现任何 invalid 时，保留全部重抽记录/原因/质量，可报告 valid-only 条件区间及完成包络作为诊断，**不能以过滤后的下界开启 +0.03/正下界/4-of-5 成功支路**。不能补抽直到只剩足够 valid、事后加伪样本，或切换成视图级重抽挽救。若要有条件/分层/加权替代方案，需先定义新目标并在未看新 audit 分数前审查，旧失败结果不覆盖。

即使观察到0个 invalid，也不自动验收区间：独立祖先数、组内类覆盖、祖先关系真实性和多来源代表性仍需协议前检查。K=1或某类只有单一祖先等明显退化情形不能据重复视图宣称足够精度；具体最小簇数须事前统计设计，不在本轮凭空指定。

样本重抽同时固定全部五个训练结果，所以区间条件于这些已训练模型。种子稳定性需真实预注册随机来源、checkpoint和完整五个 Delta[s]；不将重抽视图、数值舍入或重复确定性凸头算训练随机性。训练过程不确定性如需量化，另设同时保留方法配对和共享训练数据结构的设计，本式没有覆盖它。

AL37 的限定对象定义得以保留；“invalid已标记”不等于正式区间处理完成。AL42完成后只关闭这项设计缺口，不放行真实实验、不新增来源收益或算法准入。
