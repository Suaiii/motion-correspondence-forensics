# AL53：完整端点的必要外包络与可认证误差

2026-09-19，planagent。此文件是最终条件数学审查，取代本轮早期的 AL53_ENDPOINT_PARTIAL_IDENTIFICATION_REVIEW/EXACT 草稿判断。旧 JSON 是人工提纲，不是已运行的7项测试。本轮没有数值例、模型、真实数据或服务器调用；以下逐步推导不宣称实际 AE 已满足常数与域条件。

## 1. 必要外包络，不直接等同可实现集合

设固定 probe R 的合法输入域为U、已知输出约束为Omega，使用事前选定的输入范数||.||_X和输出范数||.||_Y。假定对涉及的所有输入对有可信界 ||R(x)-R(p)||_Y<=L||x-p||_X，L有限；仅“在开域内”本身不保证此界。真实查询位置x_i已知，记录yhat_i的输出误差<=epsilon_i，则三角不等式给

    ||R(p)-yhat_i||_Y
      <= ||R(p)-R(x_i)||_Y + ||R(x_i)-yhat_i||_Y
      <= L||p-x_i||_X + epsilon_i = r_i(p)。

因此U_R^out(p)=Omega ∩ intersection_i Ball_Y(yhat_i,r_i(p))包含真实R(p)。相容映射/误差模型诱导的真正可实现集合F_R(p)只满足F_R(p)⊆U_R^out(p)，不将二者写成等号。各查询还须共享同一R及状态，且同时满足它们之间的正则性；单独球约束可能遗漏这些耦合。

若只知||p-phat||_X<=epsilon_p，则对全部合法候选p，用统一半径

    r_i^out=epsilon_i+L(||phat-x_i||_X+epsilon_p)。

若查询位置本身仅有xhat_i、误差<=delta_i，再增加L*delta_i。epsilon_i须确实覆盖在真实查询位置的输出误差，不能把输入误差既漏掉又声称独立。如果有不规则域或部分p球不合法，正则性界仅对合法候选使用，不能跨定义域外推。

RMS与Euclidean必须统一：对维度n输入、m输出，若用两个RMS范数，L_RMS=L_2*sqrt(n/m)；同维情况下数值相同，但半径从Euclidean改RMS须按相应维度换算。不能混用AL16的mean尺度和未缩放的sum半径。

## 2. 一致性检查与固定估计误差

若U_R^out为空，则所宣称的映射、域/范围、误差或L合同不能同时成立；该情况记inconsistent_assumptions，不能靠空集合的逻辑断言“所有可能值都在阈值一侧”。非空仅为必要一致性，不能保证存在某个实际AE同时实现全部观测。

对事先固定估计m，有以下可计算保守半径：

    rho_R(m) = min_i (||m-yhat_i||_Y+r_i^out),
    ||R(p)-m||_Y <= rho_R(m)。

证明：真实值在每个球内，对每个i应用三角界，再取这些有效上界的最小值。m不必在交集里；若它离候选集合很远，半径会反映这一点。若某个球有限，外包络直径不超过2 min_i r_i^out；有界Omega还可独立约束直径。反之L/epsilon未知且无有效有界Omega时，可能没有有限证书，应标unknown，而不是把L或误差填0。

因此“精确不唯一”与“可在容差epsilon_target内估计”并不矛盾；只有可信rho_R(m)<=预定epsilon_target才支持后者。当前没有真实AE的L或epsilon_target证据，未发出任何实际误差证书。

## 3. 两完整端点与C的外包络

对p_a=r_b=R_b(u)、p_b=r_a=R_a(u)，分别传播其输入不确定性后得到U_a^out与U_b^out。联合可实现端点对的集合J一般仅包含于U_a^out×U_b^out；共享输入、跨探针约束和观测误差会造成耦合。故

    C ∈ {a-b:(a,b)∈J} ⊆ U_a^out - U_b^out，

右端是Minkowski差（不是集合差）。它是必要外包络；不同边界方向的端点即使分别在球内，也未必可由同一对相容映射同时实现。

选定C估计m_C=m_a-m_b时，||C-m_C||_Y<=rho_a(m_a)+rho_b(m_b)，另计实现相减误差。不需要端点误差独立，也不假定相关误差会相消。交集空或任何必需半径unknown时，不能写认证结果。

## 4. C的区间不能替代原q信息

AL51有K_h=C+E_h；AL52又给有限软查询不变而C/E补偿变化的构造。**原OR1的q是K_h的能量比，不是仅C的函数**。已有软输出决定的K/q可以不变，而本节C集合很宽。因此不能从C外包络直接构造原s=w^Tq的评分集合，或声称追加完整端点会自动改善原部署评分的不确定性。

若未来另定义只由C读出的诊断量，必须绑定其实际公式、分母/滤波/权重及成本，再单独传播集合；那是另一个诊断身份。如果分析原q，则需要K、分母及其联合误差，用AL16规定的原数值路径，不能把C和E独立变化拼出假的评分区间。本任务删除早期草稿中将两类区间衔接过快的表述。

任何合法、非空评分外包络落在固定阈值同侧，只认证所声明数值模型下的阈值稳定；不认证来源正确、误报率、AUROC或跨来源泛化。重复这句话不算新方法收益。

## 5. 唯一拟议新增信息规则

在看标签前指定只针对C诊断的容差和固定估计；若有可信外包络足够小，则在此容差任务下可以避免新增完整端点查询。若不能认证，且科学/资源条件满足，按事先规则查询贡献半径较大的尚未知完整端点；并列采用固定探针ID规则，不按q/来源选择。一次调用仅能直接约束它对应的端点；另一端点仍保留原不确定性，必要时至多再查询第二项。

在phat处的新测量具有输出误差epsilon_new时，对真实p的新增球半径仍为epsilon_new+L*epsilon_p；目标输入不确定性不会凭一次调用消失。把新球与旧包络求交只能保持或缩小集合，但不能保证指定容差达成；空交按合同矛盾处理，不继续加调用直到看似通过。未知L时，只有真实输入确实就是已绑定phat才能直接使用该点测量界，不能无依据传播到未知p。

该规则仅是未来的信息价值设计，阈值/常数/费用均尚未绑定，当前不授权任何额外查询。一般主h下最多两个额外端点的成本、碰撞/h=1复用、强基线可见权限及独立复核均沿用AL51；最终集不打开。
