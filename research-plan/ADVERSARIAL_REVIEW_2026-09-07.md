# 视频取证研究的反方审查与修订方案

> 2026-09-08 补充近邻：DCPT（arXiv:2604.10102）已显式使用clean/degraded特征与预测一致性。C2的普通配对训练部分不能作为新颖点，选择性视频监督必须提出并验证额外机制。当前有界转向规则见ORDER_GATE_BRANCHES_2026-09-08.md，结果尚以对应运行产物为准。

日期：2026-09-07。主线任务：本对话。定位：研究立项与机制验证阶段，尚无新模型的真实视频实验结果。

## 1. 立项判断

结论：值得做机制验证，但上一版“轨迹输运 LIF + 归一化 + GRL”的拼接方案还不能被判定为足够新颖的 CCF-A 方法。工程可实现性较高；论文竞争力取决于能否发现并证明一种视频取证特有的矛盾，而不是把已知时序算子换成脉冲神经元。

本轮建议把主问题改为：**在传播退化和不可靠运动对应下，怎样选择性地积累视频取证证据，同时避免对齐与去噪把判别信息一起消除？**

长期应用价值来自生成器持续变化与真实传播需求。具体方法不应依赖“假视频一定更抖”“假视频一定更平滑”“异常一定在边缘”这些单方向规则。我们检验不同坐标参照下的证据互补性，并允许机制在新生成器上失败。

本次是反方思考与小范围先例核验，不是独立审稿或系统性新颖性检索。未启动其他 agent；没有给出录用概率。

## 3. 反方问题、风险与判定实验

| 反方提问 | 为什么可能失败 | 判定实验与失败后的决定 |
|---|---|---|
| 对齐是不是把伪造异常也对齐掉了？ | 形变和闪烁可能被光流解释为运动；插值又会削弱高频 | 同骨干比较未对齐、仅对齐、双参照、随机/错误对应；若仅对齐持续更强，则删除双参照主张 |
| 运动对应在噪声下可信吗？ | 快运动、遮挡、重复纹理、镜头切换会造成错位记忆 | 按前后向一致性、越界和遮挡分层；人为加入对应误差；错配严重时检查记忆是否被抑制 |
| “减少脉冲”是否等于“提升检测”？ | 全静默能完美减少脉冲，却完全没有真假信息 | 同时测脉冲率、类别间距、AUROC；设置零事件和固定 firing-rate 对照 |
| sigma_hat 会不会把伪迹本身当噪声？ | 从包含生成异常的残差估计尺度，异常越大阈值越高 | 保留原尺度与标准化两组统计；比较固定尺度、局部估计与训练配对估计；若归一化抹掉区分力则不用 |
| 所有传播退化都能写成加性噪声吗？ | 编码、插帧和几何变换通常非线性、相关、依赖内容 | 将加性式降级为直觉模型；逐项干预与真实平台外测，不宣称恢复唯一生成噪声 |
| GRL 是否去掉了有用信息？ | 判别证据和质量可能共享表示方向 | 普通分类、GRL、选择性一致性三组；测不同退化强度下判别能力；GRL 默认不纳入最小模型 |
| 只凭一条未知视频能分解生成与传播吗？ | 不同源视频与退化可得到相同观测，分解一般不可辨识 | 目标改为可靠分类与风险估计；极端退化测拒识覆盖率，不承诺复原已丢失证据 |
| 视频时间真的带来了收益吗？ | 一个强帧级检测器加均值就可能足够 | 单帧、重复同帧、打乱时间、真实时间序列，保持采样预算；同时监测分布外效应，不能仅凭乱序降分证明因果 |
| 边界 Tube 是不是高成本装饰？ | 生成异常可能在纹理、背景或全局；硬 ROI 会遗漏证据 | 全图、边缘、内部、等面积随机区域、固定外圈对比；Tube 先用作分析区域，不做必需输入 |
| SNN 是否真的更值得部署？ | 光流和语义骨干可能主导耗时，Warp 是稠密运算 | 同硬件、同对应估计、同骨干、同增强的 ANN/GRU/LIF；计入全部耗时。以准确率—延迟前沿选择，不能因微小精度差立即否决低开销方案 |
| 是不是仅学到了 Vript、padding 或生成器格式？ | 源场景、时长、帧率和编码与标签相关 | 源视频分组、真假元属性探针、raw/canonical 双轨、未见真实来源与生成器测试 |

## 4. 建议新增的两个候选创新

### C1：对齐不确定性感知的双参照记忆

需要保留的矛盾是：对齐可以减少自然运动干扰，也可能消除生成异常；未对齐信息受运动污染，却可能保留画面坐标中的纹理或编码痕迹。两路均不预先被定义为“真证据”或“噪声”。

令 backward correspondence `F_t` 把当前像素映射到前一帧；`W_t` 用同一采样约定作用于输入和状态。保留：

`R_grid(t) = Y_t - Y_(t-1)`

`R_motion(t) = Y_t - W_t(Y_(t-1))`

`V_grid(t) = a_grid * V_grid(t-1) + P_grid(R_grid(t))`

`V_motion(t) = a_motion * m_t * c_t * W_t(V_motion(t-1)) + P_motion(R_motion(t))`

其中 `m_t` 为有效/遮挡掩码，`c_t` 为对应可信度，`a = exp(-dt/tau)` 保持有界。镜头切换和独立视频起点重置状态。SNN 版本在积分后执行明确定义的 ON/OFF 放电与 reset；有符号残差分正负通道，不能直接声称它是二值脉冲。

`c_t` 表示“对应是否可靠”，不是“这里是否伪造”。初版用固定的前后向一致性和越界检查，避免可学习置信度通过压低难例区域逃避分类损失。低可信度不传历史状态，但保留当前证据与另一参照分支。

读出联合 `[V_grid, V_motion, c, branch_disagreement]`，与简单 concat、平均融合、等参数双分支和无置信度输运对比。主张候选是“不同参照下的失效互补和可靠积累”，不是“用了两条分支”。

最小版固定两路总通道数：例如单路 64 与双路各 32；再做精确参数/计算量匹配。固定语义骨干与光流版本，先验证轻量读出，不立刻引入 Transformer、多尺度、Tube 和 EvAF。

### C2：由配对传播干预学习证据保留，而非全局不变

仅对训练源视频构造不同传播视图 `D_i(X)`。它们保持生成来源标签，但不保证保留全部可检测证据。空间裁剪和时间采样使用已知变换映射，只有有效重叠位置可以对应。

候选学习目标：

`L = L_cls(clean/degraded) + lambda * L_selective_pair + beta * L_budget`

选择性配对损失只约束训练阶段证据稳定、且对判别有效的时间片段/特征分量。稳定性用同源多视图差异估计；类别有效性由训练数据的分类目标与冻结/EMA teacher 辅助衡量。teacher 仅用 train 更新，置信度须经独立开发集校验，不能当作像素真值。

必须加入三个防坍缩检查：有监督分类、固定/最小有效覆盖约束、与常量特征和“全部样本权重为零”的对照。配对权重初版 stop-gradient；检查保留率与类别间距，避免只挑容易样本获得虚假稳定性。

为降低自由度，C1 在普通增强下先验收；C2 只有在无条件一致性确实损害强退化或部分区域证据时才引入。GRL、Tube、局部 sigma 归一化均为候选消融，不列作必需创新。当前没有实验能确认 C1/C2 有效，且它们仍需继续精确查重。

## 5. 有希望的理论问题与不值得包装的理论

对次高斯噪声写指数尾界属于标准工具，也不能直接覆盖依赖噪声估计的随机阈值。更相关的问题是“错配怎样在时序状态中累积”。

对于不含硬放电/reset 的线性积分核心，假定对应算子在选定范数下有界，`a<=rho<1`，在相同可信度条件下可推导：

`error_t <= rho * error_(t-1) + rho * confidence_t * warp_error_t + input_error_t`。

展开后得到一个几何加权误差和；可信度降低可能减轻旧状态错配传播，但也可能损失有用记忆。若 confidence 自身有误差，需要额外项。该式仅作为分析起点，不是完整 SNN 鲁棒性证明。

硬阈值会引入不连续，只有膜电位离阈值有足够 margin 等额外条件时，才能进一步讨论 spike pattern 的稳定性。理论工作必须给出明确假设、证明和可测量量，不能直接把这段直觉写成定理贡献。

## 6. 对抗环境评测：与反方审稿区分

本次“对抗角度”首先指反方审查。同时预留三层评测：自然传播退化；有界、保持内容的恶意后处理；模型感知的规避测试。三层分表，不能把第一层的稳定性称为 adversarial robustness。

本地安全测试仅用于自己的模型与研究样本：在训练/开发数据上选择攻击或压力条件及预算，最终冻结后测试。需要覆盖不同替代梯度、随机初始化、步数检查、迁移攻击或有限查询对照；对非可微编码考虑适当近似和真实变换复核。若多次攻击都失败，先查梯度遮蔽。报告实际扰动/内容变化、预算和成功率，不以 PSNR 一项代替所有约束。

首篇方法以被动检测、未知生成器与传播鲁棒性为主；暂不扩展到生成端主动保护、水印或新的多模态任务。

| 实验 | 比较内容 | 真正回答的问题 | 判定方式 |
|---|---|---|---|
| E1 对齐收益与证据损失 | 未对齐、对齐、concat、可信度双参照；固定骨干和总容量 | 对齐是否有可预测的取证代价？ | 开发集按运动/遮挡/退化分层；报告配对差值区间，无稳定互补就删除 C1 |

这三项是待执行实验，本轮未生成新 detector 结果。先做最小开发样本和运算 profile，再锁定 GPU 小时预算与规模；不在硬件未知时承诺训练周期或收益百分点。

可行性结论：工程上可以推进；已有数据足以开始开发诊断；新颖性目前不充分；外部数据独立性与证据保留机制，是当前最值得投入的两项工作。若主效果仅来自强增强，或 SNN 方案被较简单 ANN 全面支配，应修改论文问题，而不是继续增加模块。
