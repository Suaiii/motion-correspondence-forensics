## 3. 主候选与创新边界

核心问题：在来源、采样与预处理受到控制后，视频内部局部视觉对应关系是否存在可跨生成器迁移、且能抵抗传播退化的异常？

研究主线为局部时空对应中可验证的独立取证信息。“经匹配扰动校准的局部对应可组合性”及C作为冻结参考候选保留；v1.4开始并列检验H-J联合可实现性与H-T对应条件化高阶信息，最终方法由证据取舍。现有局部秩响应另列诊断/对照，不与这些候选混称或无证据融合。

### 3.1 表征与对应

采用冻结 DINOv2 ViT-B/14，在 224×224 输入上保留 16×16 patch 特征和全局语义向量。初版不微调大骨干，可训练参数控制在约 100 万以内。令每行 patch 特征归一化为 Z：

    P_ab = row_softmax(Z_a Z_b^T / tau), tau = 0.1

P_ab 是帧 a 到 b 的软对应矩阵，逐行和为 1。实际 PTS 用于采样审计，不把来源、生成器、编码元数据直接送入分类头。

### 3.2 直接对应与两步对应

对三帧 a、b、c，逐 anchor patch p 计算：

    d0(p) = JS(P_ac(p, :), (P_ab P_bc)(p, :))

该量仅表示对应不一致，不能直接解释成违反物理规律。真实视频的遮挡、纹理重复和运动模糊同样可以产生不一致。

### 3.3 同视频匹配扰动

仅对中间索引的一侧施加置换 Pi，保留原特征和两步计算：

    d_rk(p) = JS(P_ac(p, :), (P_ab Pi_rk P_bc)(p, :))
    R_r(p) = mean_k(d_rk(p)) - d0(p)

固定 r 为 1、2、4 个 patch，每个尺度四个方向。置换使用 16×16 网格索引的循环位移，保持严格双射；边缘绕回影响用固定内部区域对照单独核验。该对照限制各路径共同的中间节点支持并报告保留概率质量，仅裁剪 anchor 行不足以消除中间节点绕回。只打乱一侧连接与同时一致重编号要分开：后者应保持乘积不变，是软件不变量测试。

A参考协议的六帧使用相邻三元组 (0,1,2)、(1,2,3)、(2,3,4)、(3,4,5)，以及两步间隔三元组 (0,2,4)、(1,3,5)。该完整布局在已查MS/VC2中无共同支持，当前不作为已通过的受控时序训练协议。仍保留实际间隔与参考实现；下一离线分支见第3.6节。

轻量空间编码器读取响应图，跨三元组做无序聚合，再与同骨干全局语义融合。首版使用普通分类损失和统一增强。输入输出至少保留视频分数、局部响应图和独立诊断量。

### 3.4 必须能推翻方法的情况

- 普通 patch 聚合已达到相同效果。
- 使用相同六帧、相同语义输入和读出的静态 patch 对照已达到同样效果。
- 对应熵、纹理或运动强度即可解释增益。
- 去掉匹配扰动没有损失。
- 机制在第二真实来源或传播退化下消失。
- 方法与已有对应学习工作没有实质区别。

矩阵乘法、JS、循环一致性与简单融合均不是独立创新。不得把正交等同统计独立，也不得由扰动实验自动得出生成机制的因果结论。

必须比较并记录差异：[MAST](https://arxiv.org/abs/2605.05895)、[RIFT](https://arxiv.org/abs/2609.00742)、[WaveRep](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection)、[G2VD](https://arxiv.org/abs/2607.04607)、[VidAudit](https://arxiv.org/abs/2606.31004)、[TimeCycle](https://openaccess.thecvf.com/content_CVPR_2019/papers/Wang_Learning_Correspondence_From_the_Cycle-Consistency_of_Time_CVPR_2019_paper.pdf)。以上引用是近邻入口，不代表已完成复现或全面查新。

### 3.5 新增必做对照：静态重复帧与静态 patch

2026-09-17 的软件证据表明，软对应矩阵一般不满足 P²=P，因此完全静态输入也可以产生非零 JS 和扰动响应。真实冻结 DINO 在六张相同合成图上的平均 JS 为 0.03408，平均绝对响应为 0.09492。这些数值仅为单次合成检查，不是视频检测指标，也不直接否定候选。

在真实机制实验前冻结以下对照：

1. **静态重复序列检查：** 同一帧的 patch 复制六次，记录直接 JS、响应、熵与支持量；不把“静态响应必须为零”写成正确性条件。
2. **静态 patch 强基线：** 使用原视频全部六帧的冻结特征，对每帧 i 构造 (i,i,i) 三元组，共六组响应图；与完整方法同样使用三种扰动尺度、相同空间编码器和无序读出。语义分支始终保留原视频六帧，避免把少看帧或语义变化误当时间贡献。训练角色、种子、增强、容量与选择规则一致，实际计算量仍需测量。
3. **固定模型敏感性检查：** 同一已训练模型中仅替换时间分支为上述静态响应，保持语义输入不变。该检查仅用于敏感性分析，不能替代另行训练的静态基线比较。

若完整方法相对静态基线没有可靠增量，就不能声称已证明时序机制。保留原公式，不为强行得到零静态响应而临时相减、改温度或在审计集选校正。任何新校准方法须另立假设和对照。

证据：[原型报告](../research-runs/shared_plan_20260917/composability_report.md)、[冻结骨干联通](../research-runs/shared_plan_20260917/backbone_integration.json)、[静态反例](../research-runs/shared_plan_20260917/static_sequence_counterexample.json)。

### 3.6 v1.2 决策：居中三帧 C 的离线实现

经 [DX02/RS01审查](reviews/DX02_RS01_20260918.md)，选择 candidate_c_centered3_v1 作为下一软件诊断分支。该选择只允许离线CPU合成测试；正式训练协议、真实来源共同支持和PTS合同仍未放行。

    D = PTS[-1] - PTS[0] + median(diff(PTS))
    c = PTS[0] + D/2
    targets_C = [c - 0.5, c, c + 0.5]
    temporal_triplets_C = [(0,1,2)]
    static_triplets_C = [(0,0,0), (1,1,1), (2,2,2)]

沿用有限且严格递增PTS、D≥1.5−1e-6秒、最近帧选择、1e-9秒平局选较早帧和最大选择误差0.125秒的资格规则，三个原帧必须互异。该误差上限不证明实际间隔已匹配；真实数据仍须审查两个间隔联合分布、连续差异、中心偏移、覆盖和来源探针。

C的目标代数上与A的1/3/5位置相同，仅在完整PTS、处理流及选择规则相同时允许条件复用。禁止根据旧8帧缓存或标称FPS补出缺失原帧，禁止重复成六帧。

C内部每个比较臂都看同三个原帧，使用同三帧语义均值、相同头容量、独立优化器/运行和相同选择规则。时间/静态分别有1/3个响应组与13/39次组合乘积，必须报告计算差异。C的次数加权静态为均匀1/3，不另建重复加权实验。

新增起点匹配诊断：理想特征场循环平移且与扰动可交换、完整中间支持时，时间(a,b,c)响应恰等于静态(a,a,a)。已完成合成机械回放，该等式不保证真实DINO平移等变，也不覆盖固定interior掩码。C的anchor-matched-static局部分支仅用帧0静态图，语义仍用同三个原帧；它是机制诊断，不能替代同三帧uniform-static强基线。A的起点权重为[2,2,1,1,0,0]/6，与总角色次数权重不同。正式对照/训练须预先冻结并分开报告，不择弱者。证据见 [平移null审查](reviews/DX02_RS01_20260918.md)。

A默认实现及均匀静态基线保留；A的次数加权提案暂不实现，B暂不实现。不得通过变更C去改变A已归档结果。正式机制数据规模、比较门槛和预算不变，后续采样冻结仍须RS03/RS07审查。

## 4. 数据、实验与科学验收

### 数据角色与目标

| 数据层 | 目标 | 条件 |
|---|---:|---|
| 最小机制集 | 首批约 2000，随后约 6000 条 | 两个真实来源、四个生成器，祖先分组 |
| 正式训练与校准 | 合计约 12000 条 | 与开发审计、最终确认隔离；fit/calibration 按祖先分组 |
| 来源外开发 | 已暴露 ComGenVid 及新增合格开发样本 | 可分析失败，不重命名为最终集 |
| 最终确认 | 至少 7000 条，4000 真、三种未见生成器各 1000 假 | 新真实来源、未接触祖先，方法锁定后打开 |

开发优先复用 Vript、HD-VG 与既有生成器资产；最终候选为 AIGVDBench 的 OpenVid-HD、Wan、HunyuanVideo、CogVideoX 等经核实子集。这些是目标数量，不是已验收库存。只纳入能核实任务类型、来源、发布版本和研究使用条件的样本。

A参考采样为1.5秒窗口、4 fps、6帧、224像素，目标跨度1.25秒；v1.2新增C软件分支为同样1.5秒资格、居中3帧、1秒目标跨度。两个分支均未通过正式真实来源联合时间验收，不能直接启动机制训练。资格与跨度分别记录，禁止重复补帧；标称相同FPS不算消除混杂。

相同原视频、参考素材和已知生成祖先连通分组。哈希与近重复检测各司其职；未知祖先不包装为独立。黑帧、短片等规则在看新结果前冻结，报告按来源保留率。缺失局部证据的视频保留预定语义回退路径，并报告覆盖率及 support-only 对照。

第 7 天仍不能验收第二真实来源时，对已暴露 MSVD 开发池执行替代验收；替代也失败则顺延正式训练，保留阻塞并推进不依赖服务器的工作。

### 比较与消融

- 同条件：DINO 语义 MLP、均值加无序波动、时间差分、普通双视图 ERM。
- 相同 patch 输入/容量的普通聚合；仅直接误差、未校准两步误差、完整扰动响应。
- 第 3.5 节的静态重复序列、同六帧静态 patch 强基线和固定模型敏感性检查；不能仅凭响应非零解释成时间异常。
- 熵/纹理/运动与支持范围探针；空间打乱、固定内部区域、同计算量对照。
- 相同数据、骨干和训练配方下的 WaveRep 增强对照。
- STALL、D3 官方可用流程；优先完成 WaveRep 与 RIFT 的公开实现或 checkpoint 评测。原生协议与匹配协议分表，未复现结果不冒充本项目结果。
- 软件不变量：矩阵归一化、均匀对应零响应、已知置换精确组合、中间节点一致重编号不变、独立推理回放。响应图不自动称作已验证伪造定位。

### 传播与统计

训练使用 clean、H.264、温和缩放，所有类别采用相同处理分布。H.265、较强缩放和组合转码留作未见条件；先处理整视频，再抽帧。

主指标：生成器宏平均 AUROC、最差组 AUROC、校准集 1% FPR 阈值下的测试 TPR 和实际测试 FPR。固定五种子 17/29/43/59/71。报告种子均值/标准差及祖先分组配对区间；共享真实样本的生成器比较共用抽样。不把集成概率的区间解释成种子均值的区间，统计量在开最终集前固定。

### 判据

- 开发：相对预先指定最强匹配基线，macro AUROC 增益至少 0.03，配对 95% 区间下界大于零，至少 4/5 种子为正，并通过机制与混杂对照。
- 正式确认：macro 增益至少 0.02，最差组提升目标至少 0.03，clean 损失不超过 0.01，并保留未见生成器和未见传播路径收益。
- 这些是项目内部决策标准，不是录用保证。最终评测前锁定，不能因截止临近或看到结果后放宽。
- 实验完成与机制成立分开；失败可结项，成功依赖不能随之放行。10 月 15 日仍无可信方法增量时允许延期，完成预稿和失败解释，不包装开发高分。
